## 3. 学科体系分支（助手探索设计，即 W4-a 种子规范）

## 4. K12 知识点 → 分支 的映射策略（助手设计）

**桥结点选 `textbook_chapter`（622 章）**，理由：点↔章可确定性推导（code 前缀），章是人教版真实教学单元，且"**章属于哪个学科分支**"语义天然。

```
knowledge_points.code  ──前缀──►  textbook_chapter.code ──textbook_id──► textbook(人教版册/年级)
        │                                                          │
        └── mastery_snapshots（掌握度）                              └── subject_id/grade_id
                                                                     │
knowledge_area(331) ─────── curated ──────► knowledge_branch（§3 分支树）◄── curated ──── chapter.branch_id
```

**映射两层**：
1. `chapter.branch_id`（622 行，**规则 + 人工复核**）：章名关键词规则（如「机械运动」→mech、「溶液」→inorg、「分数」→num）+ 例外表；**校验 100% 落位**（无空）。
2. `knowledge_area.branch_id`（331 行，curated）：按 §3 表 + 例外表；**校验 100% 落位**。

**人教版核对**：`points.code` 内 `pep` + 年级须与 `textbook`/`grade` 一致（审计一致率 + 偏差清单）。
