## 5. 延续性设计（本设计的核心价值）

- 每个**分支**带 `k12_grade_min` / `k12_grade_max`：该分支在 K12 中出现的年级区间。
- **维度 A 视图**：分支 = 一条从山脚到顶峰的路径，**K12 段落与学科纵深段落同屏**（K12 部分用年级刻度标注 → 一眼看出"这学科分支从小学几年级一路学到大学什么"）。
- **维度 B 视图**：同一批知识按学段/年级排布，**每个年级/册标注它属于哪些体系分支**（反向照应延续性）。
- 登顶语义：`mastery ≥ 80` 且**该分支 K12 段完成** = K12 阶段登顶；分支**整体**精通 = 学科体系登顶（可含 K12 之外内容）。
