# 学科登顶 · 双维度设计（W4）：学科知识分类多顶峰 × K12 学段年级

> 状态：设计 v1 ｜ 2026-10-16 ｜ 作者：总负责人（助手）
> 依据：用户 2026-10-16 四点要求 + 实测数据底座（见 §2）
> 目标：把「登峰」从**单维度（按领域铺路线）**升级为**双维度可切换 + 多顶峰 + 拟真形象**。

## 1. 你的要求 → 设计口径

| # | 你的话 | 设计口径 |
|---|---|---|
| 1 | 顶峰=**学科知识分类的终极点**；一个学科**多个顶峰**（数学→线性代数/微积分/概率论…） | **维度 A · 学科知识分类**：每学科有 **N 个分类分支**，**每个分支一座峰、其终极点=顶峰**（多顶峰） |
| 2 | 每个分类顶峰的**知识点落在不同学段**（小/初/高/大学）；要按**人教版编排**找出 K12 教学安排 → 关联年级 → 服务评估/学习计划 | **维度 B · K12 学段年级**：按 **学段/年级** 组织，**依人教版编排**关联知识点；为评估/计划提供依据 |
| 3 | 两种维度（学科顶峰 / K12 顶峰）→ 要**切换开关** | 登峰页**维度切换**（学科分类 ↔ K12） |
| 4 | 现登峰 UI **太简单单调不形象**，要达**生活场景那档**直观形象 | **UI 升级**：对齐人本世界/学习世界的**同一世界语言 + 拟真形象 + 信息密度** |

## 2. 数据底座（实测）

- `ontology.knowledge_area`（331）：**领域 → 知识域 → 前沿**两级树（自引用 `parent_id`）；`scope` = `k12`(303, 带 `grade_level` 1–12) / `frontier`(28, 无年级=峰外/大学·前沿)；`subject_id`。
  - 每学科 root 领域数：**数学 4**（数与代数/图形与几何/统计与概率/综合与实践）、语文 6、生物/化学/英语/物理 5。
  - 数学**前沿分支**样例：抽象代数 / 实分析 / 复分析 / 拓扑学 / 微分几何 / 数值分析（≈"科学分支"，可作**顶峰**候选）。
- `edu.knowledge_points` **2908** 条，`grade_level` 已按 **G1–G12** 填充（每级 ~70–470）。
- 本体 `k12-curriculum`：`Subject / SchoolStage(小/初/高) / Grade(G1–G12) / Textbook(人教版…) / TextbookChapter / KnowledgePoint / KnowledgeArea` + 前置 `area_prerequisite`。
- 现有读面 `GET /api/curriculum/knowledge-map?subject=`：返回 `areas`(含 scope/grade/parent) + 前置边 + **按年级聚合的 kpCounts + 掌握度**；`GET /api/curriculum/{subjects,knowledge-graph}`。

## 3. 双维度模型

```
学科（数学）
 ├─ 维度 A · 学科知识分类（多顶峰）          ┌── 峰1 数与代数 ──……──► 顶峰(终极点)
 │   每学科 N 座峰（数学 4；前沿科学分支可作独立峰/顶峰）   ├── 峰2 图形与几何 ──……─► 顶峰
 │                                          └── 峰N …（抽象代数/实分析/复分析…）
 └─ 维度 B · K12 学段年级（人教版编排）
     小学 G1–G6）→ 初中(G7–G9) → 高中(G10–G12)          K12 顶峰 = 走完 K12
```
- **切换开关**：顶部维度切换（学科分类 / K12）；同一批知识点，两种组织方式。
- **掌握度/登顶**：沿用 `mastery ≥ 80 = 已登顶`；两维度下按各自节点聚合。
- **人教版关联**：维度 B 的年级关联**以人教版教材编排为准**（现状 `grade_level` 已有；本卡须**核对**是否与人教版一致，偏差走数据轨修正）。
