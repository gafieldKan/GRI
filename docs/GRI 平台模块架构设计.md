# GRI 平台模块架构设计

## 一、模块划分原则

### 1.1 核心原则
- **一级模块 = 行业维度** (ISIC 行业分类)
- **二级模块 = 功能维度** (业务场景/子行业)
- **三级模块 = 服务模式** (定制化/传统/自助等)
- **末端 = 具体功能应用**

### 1.2 ISIC 行业分类映射

| GRI 一级模块 | ISIC 代码 | 说明 |
|-------------|-----------|------|
| 农业 | A01 | 种植、养殖 |
| 食品制造业 | C10-C12 | 食品加工 |
| 批发业 | G46 | 食材批发 |
| 零售业 | G47 | 零售贸易 |
| 物流业 | H49-H53 | 运输、仓储、配送 |
| 餐饮业 | 5610-5630 | 餐馆、快餐、饮料店 |
| 住宿业 | 5510 | 酒店、旅馆、度假村 |
| 专业服务 | M69-M75 | 法律、会计、咨询 |

### 1.3 资源归属判定规则

| 资源类型 | 一级模块 | 判断依据 |
|---------|---------|---------|
| 餐厅、厨师、菜品 | catering (餐饮) | 提供餐饮服务 |
| 厨房 | catering (餐饮) | 餐饮制作场所 |
| 农场/基地 | agriculture (农业) | 农业生产场所 |
| 农作物 | agriculture (农业) | 农业产品 |
| 农户 | agriculture (农业) | 农业从业者 |
| 食品加工厂 | manufacturing (制造业) | 食品加工场所 |
| 食材批发商 | wholesale (批发业) | 批发贸易主体 |
| 物流公司 | logistics (物流业) | 运输服务主体 |
| 配送员 | logistics (物流业) | 物流配送人员 |
| 酒店 | accommodation (住宿业) | 住宿服务场所 |
| 门店 | retail (零售业) | 零售服务场所 |

## 三、跨行业业务流程分析

### 3.1 一份菜品的完整生命周期

```
┌─────────────────────────────────────────────────────────────────┐
│ 一份菜品涉及的跨行业模块协作                                      │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 农业模块 (A01)          2. 批发业模块 (G46)                  │
│     ┌─────────────┐            ┌─────────────┐                   │
│     │ 农户种植蔬菜 │───────────→│ 食材批发商  │                   │
│     │ (种植管理)  │            │ (采购管理)  │                   │
│     └─────────────┘            └──────┬──────┘                   │
│                                       │                          │
│                                       ↓                          │
│  4. 餐饮业模块 (56)           3. 物流业模块 (H49-H53)            │
│     ┌─────────────┐            ┌─────────────┐                   │
│     │  厨师制作   │←───────────│  配送员配送  │                   │
│     │ (厨房管理)  │            │ (配送管理)  │                   │
│     └──────┬──────┘            └─────────────┘                   │
│            │                                                       │
│            ↓                                                       │
│     ┌─────────────┐                                               │
│     │  用户享用   │                                               │
│     │ (点餐系统)  │                                               │
│     └─────────────┘                                               │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 模块归属说明

| 业务概念 | 一级模块 | 二级模块 | 说明 |
|---------|---------|---------|------|
| 蔬菜种植 | agriculture | 种植管理 | 农业生产环节 |
| 食材采购 | wholesale | 采购管理 | 批发贸易环节 |
| 食材运输 | logistics | 配送管理 | 物流运输环节 |
| 菜品制作 | catering | 厨房管理 | 餐饮服务环节 |
| 用户点餐 | catering | 点餐系统 | 餐饮服务环节 |

**关键设计**: 不同行业环节由不同一级模块管理，实现业务边界清晰、数据隔离。

## 六、总结

本设计实现了：

1. **行业维度优先**: 一级菜单按 ISIC 行业分类组织
2. **功能维度次之**: 二级菜单按业务功能划分
3. **服务模式再次**: 三级菜单按服务模式区分
4. **应用挂载**: 具体功能应用挂载在末端
5. **跨行业边界清晰**: 配送、供应链等业务正确归属对应行业模块

符合 GRI 平台"宏观一致性 + 微观灵活性"的设计理念。
