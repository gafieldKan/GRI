# 学科登顶 · v4 设计：黎明破晓 × 光脉传导

> 状态：**设计 v4（用户 2026-10-19 裁决：色彩=「黎明破晓」；核心机制=「光脉传导」）** ｜ 作者：总负责人（助手）
> 承接：`docs/SUBJECT_SUMMIT_DESIGN.md`（v3：双维度 = 学科知识体系全覆盖 × K12 阶段、中图法权威锚定、延续性字段）。
> v4 **不推翻 v3 的数据与双维度**；v4 重构的是**体验机制**——把"静态风景图"升级为"会因你的学习而点亮、生长的世界"。
>
> **用户原话（2026-10-19）**：*"采用 A（保留山为宏观骨架），但方案都是围绕我举例的场景设计的，我需要更开拓的视角和思维拓展，希望效果能更科幻、更吸引人、更能够体现学习过程，达到引导和帮助学生学习的效果。"*
> 裁决：① 色彩方向 **黎明破晓**（浅色系，现有令牌内可做，低成本）；② 引入 **光脉传导**（本设计灵魂）。

---

## 0. 为什么 v3 的页面"不吸引人"（根因诊断）

**不是画得不够花，而是地图只表达"状态"，不表达"因果传导"。**

知识的本质属性是**前置依赖**——掌握 A，B 才向你打开。v3 的山是**静态风景**：峰上有旗、有进度条，但**不会因为学生的动作而变化**。学生看到"我在哪"，却看不到"我点亮这里，那里就亮起来"。学习是动词、是时间、是累积；而静态的山是名词。

**v4 升级的不是画法，是机制。**

---

## 1. v4 一句话

**不再是"去看一座画好的山"，而是"点亮你的星穹/晨山——光会沿着你打通的链一路向前，把黎明前的黑暗里的山脊一段段照出来。"**

山**保留为宏观骨架**（承接 v3 双维度），但它是**"被点亮才显现"的**。

## 2. 三大机制（让"学习过程"可见）

| # | 机制 | 表现 | 直接回应用户要求 |
|---|---|---|---|
| **M1** | **晨雾即未知** | 世界初始只有山脚（K12 起点）可见，其余被**黎明晨雾**罩住，只有轮廓微光 | 让学生**一眼看出"我走过的路"和"还没走的路"** |
| **M2** | **光脉传导即因果**（灵魂） | 答对一个知识点 → 该点亮起 → **光沿"基础→进阶"链流向它的后继点**（后继从"暗不可进"→"微光可进"）→ 晨雾退散、山脊显现 | **可视化"掌握基础才能向上"**；这是全案区别于静态风景的关键 |
| **M3** | **洞窟即闭环** | 点击已点亮的洞 → 探入 → **平铺 SVG 生活场景**（复用生活场景画法）→ 洞内跑**智学慧眼完整闭环**（讲解→练→判→错题/复习计划→掌握≥80→出洞）→ 亮灯 + 奖励 | 打通"学科完整学习体系"与"K12 学习体系"；**整合而非重写**智学慧眼 |

### 2.1 引导力（"帮助学习"的落地，必须具体）

- **晨雾只能被相邻的光驱散** → 结构性地告诉学生"下一步该去哪"。
- 每次进入世界，一个**"下一个最佳目标"脉冲呼吸提示**（由掌握度 + 课程序列算出）。
- **洞门三态**：`未进过=暗门` ／ `进过未掌握=半亮` ／ `掌握≥80=亮灯`。
- **答错不惩罚**：只"暗淡回摆"并自动接错题/复习闭环（呼应"间隔复习"）。

## 5. 中观：洞窟（知识点）如何排布在山上

**数据真源**：`edu.knowledge_points`（**2908** 条；`grade_level` 覆盖 2907 / `chapter_id` 2873 / `code`=`math.g1.pep.ch02.s01.kp03`）。

**排布序**（每座峰内，自山脚向峰顶）：
```
年级 grade_level 升序
  → 册 textbook.sort_order
    → 章(单元) chapter(sort_order)
      → 节 chapter(child, sort_order)
        → 知识点 knowledge_points(sort_order, code 尾号 kpNN)
```
- 海拔 y 由 `gradeY(grade_level)` 决定（延续 v3）；**同学段内按课程序列微调**，保证"从山脚到山顶连续、不断层"（直接回应用户「连续」要求）。
- **章(163 单元)/节(459)** 两层天然存在 → 可推导有序骨干。

### 5.1 洞窟粒度（**用户 2026-10-19 裁决：采纳建议**）

**1 洞 = 1 节（459 洞）**；**洞内再展开到知识点**（2908 kp 为洞内层级，不直接铺在山面上）。
- 理由：1 洞=1 kp（2908 洞）会视觉过载；节级（459）既保连续又不爆。
- **山面上的可点亮单元（光脉传导的节点）= 节**；洞内教学/判题/掌握度仍落到**具体知识点**（复用智学慧眼闭环）。
- 承接：`ontology.textbook_chapter` 的**子层（459 节）**为洞；其父（163 单元）为峰面上的"区段"，节按其下 kp 聚合掌握度。
- **无节层的峰/章**（如某些纵深或无子节的章）→ 降级为**以章为洞**（兜底，须在 W5-a 说明覆盖）。

## 6. 核心难点与诚实依赖：先修链（光脉传导的燃料）

**问题**：光脉传导需要"基础→进阶"的**链/DAG**，而 `edu.knowledge_points.prerequisites` **仅 22/2908 条**——**不能只靠现成字段**。

**方案（W5-a 数据面卡）**：由**课程序列推导**出一张**只读**"学习链"图：
1. **骨干链（纵向）**：同分支内按 §5 排布序串联，`A → B`（前一个 kp 指向后一个 kp），构成山径主线。
2. **跨分支/跨年级回链（横向）**：优先级——
   - ① **显式 `prerequisites`**（22 条，最高优先，覆盖推导）；
   - ② **同章/同节内 kp 序**（强关联）；
   - ③ **同分支、跨年级的近邻节点**（如 G5 某 kp ← G4 同分支末节点）——**降级/软边**，仅用于"雾退散"的视觉传导，不声称精确前置。
3. **输出只读接口**（新增，**不改**既有 3 个 summit 端点契约）：
   - `GET /api/curriculum/learning-chain?subject=&branch=` → `{ nodes:[{code,name,grade,chapter,mastery,state}], edges:[{from,to,kind:'explicit'|'seq'|'soft', reason}] }`
   - `GET /api/curriculum/kp-cave?kpId=` → 洞内闭环所需的单点聚合（掌握度、题目入口、错题、复习到期、下一步）。
   - **边需带 `kind`**，前端据此区分"硬约束（必须掌握）"与"软路径（引导）"，**不误导**。

> **诚实声明**：`soft` 边是**引导性**的，不是数据断言；UI 必须有可读的说明口径，避免"编造前置"。

## 7. 微观：洞窟内（平铺生活场景 + 智学慧眼闭环）

点洞 → 探入 → **平铺 SVG 场景页**（复用 `world-art` 平铺/生活场景既有画法与 `LifeWorld.vue` 语言）→ 洞内主线**全部复用智学慧眼现成能力**：

| 步 | 能力 | 现成端点（`tuition`/`curriculum`） |
|---|---|---|
| 讲解 | kp 级教学 | `getAgentLesson(kpId,stage)` |
| 出题 | kp 定向题目 | `getAgentKpQuestions(kpId,size)` / `getKpQuestions` |
| 作答&判 | 判题 | `gradeAgentAnswer(...)` / `practice/answer` |
| 会话 | 练习会话 | `practice/session/start`+`complete` |
| 错题 | 错题本 | `wrong-questions/*` |
| 复习 | 间隔复习 | `practice/sr-queue/:id` |
| 计划 | 学习计划 | `plans/generate` + `plans/:id/progress` |
| 掌握 | 真源 | `edu.mastery_snapshots`（**阈值 ≥80**） |
| 奖励 | 成就 | `user/:id/achievements`（**当前 0 条，需点亮逻辑**） |

**出洞条件**：掌握 ≥80 → **洞窟亮灯** + 奖励 + 光脉自动向前传导（回 M2）。

## 8. 两条体系的贯通（用户第 4 点）

- **人生/生活场景**是入口与外壳（`LifeScene`）；学科山是其中的**具身化学习景观**。
- 山径**自然覆盖 K12 学段**（台地）**与学科纵深**（峰顶之上）——同一座山即"K12 学习体系"与"学科完整体系"的合体，正是用户要的"直观引导学生完成两条体系"。
- 不强制登顶：登顶是**峰级**成就，日常驱动是**洞窟逐点点亮**（降低门槛、增强持续吸引）。
