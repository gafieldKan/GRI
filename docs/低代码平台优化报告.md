## 优化内容

### 1. 修复 BaseEntity 状态验证逻辑

**问题**: 构造函数中状态验证成功后未正确保存传入的状态值

**修复**:
```javascript
// 修复前
if (config.status !== undefined) {
  try {
    TypeValidator.validateEnum(config.status, EntityState, 'config.status')
    // 缺少赋值语句
  } catch {
    this.#status = 'active'
  }
}

// 修复后
if (config.status !== undefined && config.status !== '') {
  try {
    TypeValidator.validateEnum(config.status, EntityState, 'config.status')
    this.#status = config.status  // 正确保存状态值
  } catch {
    this.#status = 'active'
  }
}
```

### 2. 添加 status setter 钩子触发

**增强**: 在 status 变更时自动触发 `beforeUpdate`和`afterUpdate` 钩子

```javascript
set status(value) {
  const oldValue = this.#status
  this.#beforeChange('status', oldValue, value)
  this.#status = value
  this.#updatedAt = Date.now()
  this.#afterChange('status', value)
  // 触发更新钩子
  this.#hookManager.triggerSync('beforeUpdate', { field: 'status', oldValue, newValue: value })
  this.#hookManager.triggerSync('afterUpdate', { field: 'status', oldValue, newValue: value })
}
```

### 3. 增强 PermissionManager 权限方法

**新增方法**:
- `hasPermission(userId, permission)` - 检查用户权限
- `setMenuPermission(menuId, roleId, allowed)` - 设置菜单权限
- `hasMenuPermission(menuId, roleId)` - 检查菜单权限
- `setActionPermission(action, roleId, allowed)` - 设置操作权限
- `hasActionPermission(action, roleId)` - 检查操作权限

### 4. 修复测试导入问题

- 修复 `PluginRegistry.test.js` 中 `PluginType` 导入路径

- 添加 `dataPermissionManager` 导出

### 5. 完善核心模块导出
