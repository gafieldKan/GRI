## API 接口说明

小程序需要后端提供以下 API：

| 接口 | 说明 | 方法 |
|------|------|------|
| `/api/restaurants` | 商家列表 | GET |
| `/api/menu?restaurantId=1` | 菜单 | GET |
| `/api/cart` | 购物车 | GET/POST |
| `/api/orders` | 订单列表 | GET/POST |
| `/api/user/info` | 用户信息 | GET |
