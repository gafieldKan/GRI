# 餐饮生态平台 - 总体设计与实施计划

## 一、项目背景与愿景

### 1.1 项目愿景

构建一个**全链条餐饮生态平台**，实现从农田到餐桌的全流程可追溯、全角色协同的餐饮服务生态系统。

### 1.2 核心差异化

与传统外卖平台的本质区别：

| 维度 | 传统外卖平台 | 本生态平台 |
|------|-------------   |-----------|
| 追溯深度 | 仅到餐厅 | 农户→食材→厨师→厨房→餐桌 |
| 角色覆盖 | 用户/商家/骑手 | 8 大角色全协同 |
| 组织管理 | 无 | 支持层级化组织架构 |
| 资源仿真 | 无 | VR 视角资源展示 |
| 合规性 | 基础审核 | 线上合规签字手续 |

## 二、业务场景分析

### 2.1 核心业务场景

**场景：一次完整的用餐服务**

```
1. 用户小明要举办家宴，打开平台
   ↓
2. 浏览"私厨到家"服务，选择"川菜"菜系
   ↓
3. 查看可选厨师列表，选择"张师傅"（特级川菜厨师）
   ↓
4. 指定食材来源：
   - 猪肉：选择"阳光农场"（可追溯养殖记录）
   - 蔬菜：选择"绿源合作社"有机蔬菜
   - 调料：选择"海天"品牌
   ↓
5. 选择服务方式：使用公共厨房/上门制作
   ↓
6. 确认订单，支付
   ↓
7. 厨师接单，准备食材
   ↓
8. 配送员取货配送
   ↓
9. 完成服务，评价
```

### 2.2 角色体系

| 角色类型 | 具体角色 | 核心职责 |
|---------|---------|---------|
| **C 端用户** | 订餐人 | 点餐、评价、支付 |
| **商家端** | 餐厅管理员 | 餐厅运营、菜品管理、订单处理 |
| **服务提供** | 厨师 | 菜品制作、个人品牌运营 |
| **供应链** | 食材供应商 | 食材供应、订单处理 |
| **供应链** | 农户 | 种植/养殖、产品发布 |
| **物流端** | 外卖员/配送员 | 订单配送 |
| **运营端** | 平台运营人员 | 公共资源管理、商家审核 |
| **管理端** | 平台管理人员 | 系统运维、合规审核、基础数据 |

## 七、关键技术方案

### 7.1 组织层级管理方案

采用路径枚举法 (Path Enumeration) 存储组织层级：

```javascript
// 组织模型
Organization: {
  id: 'org_001',
  name: '某某餐饮公司',
  parentId: null,  // 根组织
  parentPath: '/',  // 层级路径
  level: 1,  // 层级深度
  type: 'company',  // 组织类型
  status: 'active'
}

// 挂靠人关系
OrganizationMember: {
  id: 'om_001',
  organizationId: 'org_001',
  userId: 'user_001',
  role: '法人',  // 在组织中的角色
  signedAt: '2025-01-01',  // 签字时间
  signedBy: 'user_002',  // 签字人
  status: 'active'
}
```

### 7.2 资源仿真展示方案

采用 Three.js + 全景图片实现简易 VR 展示：

```javascript
// VR 展示组件
<VRViewer
  type="restaurant"  // restaurant | kitchen | farm
  resourceId="res_001"
  images={['全景图 1', '全景图 2']}
  hotspots={[
    { position: [0, 0, 0], label: '灶台区', link: '/kitchen/1' }
  ]}
/>
```

### 7.3 电子签名方案

采用 canvas 手写签名 + 数字证书：

```javascript
// 电子签名组件
<ElectronicSignature
  userId="user_001"
  documentId="contract_001"
  onSign={(signature) => {
    // 保存签名图片和数字证书
  }}
/>
```

### 7.4 订单状态机设计

使用状态模式实现订单状态流转：

```javascript
// 订单状态定义
const OrderStatus = {
  PENDING: 'pending',      // 待支付
  PAID: 'paid',           // 已支付
  CONFIRMED: 'confirmed',  // 已确认
  COOKING: 'cooking',     // 制作中
  READY: 'ready',         // 待配送
  DELIVERING: 'delivering', // 配送中
  COMPLETED: 'completed',  // 已完成
  CANCELLED: 'cancelled'   // 已取消
}

// 状态流转规则
const StatusTransitions = {
  [OrderStatus.PENDING]: [OrderStatus.PAID, OrderStatus.CANCELLED],
  [OrderStatus.PAID]: [OrderStatus.CONFIRMED, OrderStatus.CANCELLED],
  // ...
}
```
