## 1. 根因诊断（实测证据，非主观）

在**线上 dist**（真实浏览器，`testuser` 登录，1500×1080），用几何探针量三个维度的实际渲染：

| 维度 | 实测（`[data-map]` viewBox `0 0 1200 820`，场景显示 **838×573px** → 缩放 **0.70**） | 结论 |
|---|---|---|
| **学科知识体系** | 20 热区 / 10 峰，坐标分布正常 | 尚可 |
| **K12 阶段** | **23 个册热区实测 x=78–193、y=388–453**（≈ **115×65px** 的方块）；SVG 内 `polygon=74` | **23 册全叠在一角** → 一团糊；纵向「年级海拔」没把册拉成可读阶梯 |
| **学科城区** | 76 店（y≈444）/ 6 门（y=514,578）/ 12 里程碑（y=532）；**城区主内容只占 y≈440–580**（画布高 573px 的可视区 → 仅**下 1/4**）；其上是山体剪影。HTML 叠层合计 **hotPins=105**（23 册 + 76 店 + 6 门），**大量重叠** | **城区被压扁在底部窄带 + 顶部仍是山体 + 叠层糊在一起** → 「看不清城区建设内容」 |

### 三条结构性根因

1. **三个维度共用同一块 `1200×820` 画布 + 同一根海拔轴**。
   切维度只换叠加层：`scenePrims` 在 `grades` 推入 `stageBands`、在 `district` 推入楼门，但**山体 / 海拔轴 / 峰始终在**。
   → 用户说的「**K12 阶段界面被错误放进城区页面**」**不是错觉**：城区页里确实残留整套 K12 与峰的表达（v5 §2 甚至把「横 = 年级大道（K12）」**塞进城区当一维**，正是本次要被推翻的一点）。

2. **城区缺独立布局网格**：楼门仍沿峰的散点坐标铺开，没有「街区 / 楼栋」的行列骨架 → 挤成一排、还压在山脚。

3. **与参考《生活全景》的硬差距**：
   - 参考：`LifeWorld.vue` = `lw-scroll`（`overflow:hidden`）+ `lw-canvas`（**等比画布**）+ `lw-svg`，场景各有**干净坐标**（`buildWorldScenes` 定位），底图 `TERRAIN` 只铺一层、**不换**。
   - 登峰页：`map-scene` = `width:100%` + `min-width:560px` + `aspect-ratio:1200/820`，把 1200 宽**硬压进 838px**（缩放 0.70）后，再叠 105 个 HTML 标签 → **必然重叠糊**。

## 2. v6 一句话

**三个维度 = 三块自洽的场景，各自一张画布、各有一套坐标；切维度 = 换世界，不再换叠加层。**

| 维度 | v6 定位 | 画布 | 坐标语言 |
|---|---|---|---|
| **学科知识体系** | 保留 v4/v5 的**群峰**（宏观骨架，已验收） | 沿用 `SUMMIT` 1200×820 | 峰 = 分支，海拔 = K12 延续带 |
| **K12 阶段** | **升学阶梯**：横向 12 年级 × 人教版册卡（**独立画布，不掺峰与城区**） | **新** `STAIR` 画布（见 §3） | 年级 = 列，册 = 阶梯卡，章 = 卡内层 |
| **学科城区** | **街区网格**：街区 = 分支，楼 = 章，门 = 知识点（**独立画布，移除年级大道与峰**） | **新** `CITY` 画布（见 §4） | 行 = 街区，列 = 楼栋，门 = 店门 |

**核心裁决：把 v5 强塞进城区的「年级大道」整条移除**（这正是「K12 界面混进城区」的根因）。K12 的年级表达**只**存在于 K12 维度。

## 3. 「K12 阶段」= 升学阶梯（独立场景）

**隐喻**：一条**从小学到高中的登山台阶路**，每级台阶 = 一个年级；台阶上摆着该年级的**人教版册卡**（上/下册）。

### 布局（`STAIR` 画布，建议 `1600×760`，可横向滚动，参考 `lw-scroll`）

- **横向 = 12 年级**（小一→高三），等距 12 列，列宽 `~110px`，总宽 `~1500px` → **画布横向可滚动**（`min-width` 而非硬缩）。
- **纵向 = 学段台阶**：小学（低）/ 初中（中）/ 高中（高）**三段台阶逐级抬升**，学段之间有**台阶断面**（视觉分隔）。
- **册卡**：每列 2 张卡（上册 / 下册，缺册则只 1 张），卡上写「七上 · 数学七年级上册」+ 章数；**卡不重叠**（列内纵向排布，列间等距）。
- **章**：展开在**右侧抽屉 / 卡内折叠**，不再散落到画布。

### 必须消除（用户反馈点）

- ❌ 峰、山体剪影（**属维度 A，不得进 K12 页**）
- ❌ 城区楼门、里程碑（**属维度 C**）
- ❌ 23 册叠在一角（v5 实测缺陷）→ 改为**12 列 × ≤2 卡的不重叠阶梯**

### 保留（v3/v4 已验收）

- 学段划分口径 `STAGE_SPANS`（小学 1–6 / 初中 7–9 / 高中 10–12）
- 册→章→节 的下钻；「我在读」标记；空态话术（「该学科的 K12 册尚未收录」）

## 4. 「学科城区」= 街区网格（独立场景）

**隐喻**：一座**按学习顺序生长的城**——**街区 = 学科分支**，**楼 = 章**，**店门 = 知识点洞口**。

### 布局（`CITY` 画布，建议 `1600×900`，可横向滚动）

- **行 = 街区（学科分支）**：每条分支一条街区带，带首给街牌（分支名）。
- **列 = 楼栋（章）**：街区内按章顺序**等距排楼**，楼与楼留步道间隙（**不再散点重叠**）。
- **店门 = 知识点**：楼的**底商门面**按 KP 顺序排列；门态三态沿用 `--world-storefront-*`（`lit / half / dim`）。
- **路 = 学习顺序**：楼间连**街道**；未掌握前置前的路段 = **施工围挡 + 晨雾**（沿用 v5 M2 口径）；打通 → 路点亮 → 光顺路流向下一栋。
- **图例**（城区专属）：楼态（已点亮 / 有作答未达标 / 未收录）+ 路态（通 / 围挡）+ **口径逐字**「路的先后是课程序列（先学后学的顺序），**不是难度高低**」「半亮 = 有作答且未到 80，**不是「会了一半」**」。

### 必须消除（用户反馈点）

- ❌ **年级大道**（v5 §2 塞进城区的那一维）→ **整条删除**
- ❌ 山体 / 峰 / 海拔轴（**属维度 A**）
- ❌ K12 册热区（**属维度 B**）
- ❌ 76 店挤在 y=440 一排 → 改为**街区 × 楼栋网格**，行距/列距均留白

### 保留

- 楼门三态真源 `deriveLightState`（掌握度 ≥80 才 `lit`，沿用 v4/v5）
- 空态话术（`chn/eng` 无节洞数据 → 明确空态 + 回维度 A 按钮；不造假楼）

## 5. 技术规格（「最新 SVG 技术」的落地口径）

沿用并强化参考《生活全景》的 SVG 实践，**非 3D、零裸色、一份画法**：

| 技术 | 用途 | 说明 |
|---|---|---|
| **独立 `viewBox` + `preserveAspectRatio="xMidYMid meet"`** | 每维度一画布 | 结构分离的物理基础 |
| **横向滚动画布**（`overflow-x:auto` + `min-width`） | K12 阶梯 / 城区网格 | **不再硬缩**（v5 糊的根因）；对齐参考 `lw-scroll` |
| **`<defs>` + `<linearGradient>` / `<pattern>`** | 路面、台阶断面、楼窗网格 | 当前画布 `defs=1` → 可增 |
| **CSS `transform` + `will-change`** | 光脉传导、门态切换、hover 抬升 | 走 GPU 合成，避免逐帧重建 DOM（v5 N11 口径） |
| **`requestAnimationFrame` 补间** | 光脉沿线流动 | 帧率友好 |
| **`<use href="#…">` 符号复用** | 楼、门、台阶卡 | 减 DOM 体积（城区曾 105 个 HTML 叠层） |
| **`prefers-reduced-motion`** | 尊重降级 | 动画可关 |
| **`aria-label` + 键盘可达** | 无障碍 | 沿用参考 `ariaLabel` |

**红线**：画法原语一律加到 `packages/world-art/src/art.js`（**零色值**）；颜色只走 `--world-*` 令牌（`styles/tokens/themes/persona-world.css`）；几何类走 `styles/world.css`（`.w-*`）。

## 6. 验收标准（可机器判定）

1. **场景分离**：K12 维度 DOM 内**不含**城区元素（`[data-storefront]` / `[data-kp-door]`）与峰元素；城区维度 DOM 内**不含** `[data-avenue-mark]`（年级大道）与 K12 册热区。← 用探针断言数量 = 0。
2. **不重叠**：同维度内任意两个同级元素包围盒**交集面积 = 0**（K12 册卡 / 城区楼栋）。← 几何断言。
3. **画布不硬缩**：K12/城区画布 `scrollWidth > clientWidth`（横向可滚动），或元素密度达标（每列 ≥1 卡且列距 ≥ 卡宽）。
4. **城市可读**：城区楼栋**行数 = 分支数**、每行楼栋**不重叠**、楼态图例存在。
5. **动画**：光脉传导可复现（前后节点 `state` 变化 `dim→half→lit`）；`prefers-reduced-motion` 下可静态呈现。
6. **不回归**：维度 A 群峰、延续性、册章详情保持（对拍 v4/v5 验收点）。
7. **零裸色**（三重 grep 空）；`world-art` 零色值；非 3D；`build:h5` 通过；真实浏览器 **`pageerror=0`**。
8. 空态话术齐全；核心路径 **≤2 步**；不 commit / 不 checkout；凭据零泄漏。
