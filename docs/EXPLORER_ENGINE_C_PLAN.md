## 0. 定位：首页从「SSO 工作台」升级为「双维度资源定位入口」

```
以人为本 → 以人引出万物 → 由万物引出本体
        └─ 首页 = 你站在哪（区域）× 你做什么（行业）→ 定位到「资源/主体/服务」
```

- **默认视图**：**全球地图**（region 维度 × geo 视图）
- **一键切换**：**行业视图**（industry 维度 × treemap 视图）
- **右上角**：未登录 → **登录 / 注册**；已登录 → 头像菜单（工作台 / 退出）
- **未来**：地图上叠加"**资源**"，按 `region × industry` 定位

## 1. 引擎架构（C 的核心）

```
ExplorerEngine({ taxonomy, dataSource, views[], skin })
   ├── TaxonomyTree        # 通用层级树（逐层展开/计数/收藏）
   ├── VisualStage         # 视图宿主，可插拔
   │     ├── GeoView       #   地理地图（region）
   │     ├── TreemapView   #   空间填充（industry）
   │     ├── GraphView     #   层级图
   │     └── ListView      #   列表
   ├── DetailPanel         # 明细（标签页/子级/笔记/关联）
   ├── GlobalSearch        # 搜索（Ctrl+K）
   ├── Breadcrumbs / 返回上级 / 全景
   ├── ExportMenu          # Excel / PNG / JSON
   └── Favorites / Notes   # 收藏 / 笔记（持久化）
```

- **视图 = 插件**：登记 `{name, render(node, ctx)}` 即可扩展（对应项目"对象→模式"的**策略/注册表**）。
- **本体驱动**：引擎只认「本体树 + 视图契约」；`region`/`industry`/未来 `subject`/`knowledge_area`/`twin` 都是**实例配置**。
- **皮肤走令牌**：`styles/tokens/`（禁裸色）；参考的 teal≈twin 青，融入顺滑。

## 2. 首页规格（首页优先）

```
┌───────────────────────────────────────────────────────────┐
│ ◈ GRI   [区域 ▾] [行业] [🔍 搜索…]            [登录] [注册] │  ← 顶栏（SSO 右上）
├───────────────────────────────────────────────────────────┤
│   ◱ 可视化舞台（默认：全球地图）                            │
│      · 点选国家/区域 → 下钻 + 右侧明细                      │
│      · 缩放/平移/复位/全屏/地名开关                          │
│      · 切「行业」→ treemap（门类→大类→…）                    │
│                                                             │
│  [左：维度树/热门]                    [右：明细/资源位]      │
└───────────────────────────────────────────────────────────┘
```

- **顶栏右**：`登录 | 注册`（未登录）；`头像▾`（工作台/退出）（已登录）。深链 `?next=` 保留。
- **维度切换**：`区域 | 行业` 按钮/菜单（对应 region/industry 实例）。
- **资源位（未来）**：选中 `region×industry` → 右侧显示该交叉下的资源。

## 4. 我的丰富建议（凭经验，供你取舍）

1. **首页=资源定位入口**（不只是看图）：维度是**筛选轴**，最终导向"资源/主体/服务"检索——呼应"以人为本"。
2. **SSO 右上**（按你要求）：未登录**显式**「登录/注册」；登录后**头像菜单**（工作台/账号/退出）；**深链保留 `?next=`**。
3. **几何性能**：默认**轻量世界底图**（简化国界）；放大/下钻再加载细节；或预生成 **SVG path / GeoJSON 瓦片**；极端情况**静态 PNG 兜底**。
4. **真地图 vs 抽象图**：Geo（真实边界，重）+ Treemap（抽象，轻）各有用；**默认区域=Geo、切行业=Treemap**（你的诉求正好匹配）。
5. **主题/暗色**：引擎皮肤并入 GRI 令牌，支持**暗色**（参考已含暗色雏形）。
6. **双语**：地图名/行业名**中英切换**（参考已有）。
7. **A11y**：键盘可达 + ARIA + `reduced-motion`（**保留参考的 A11y 实现**，别丢）。
8. **深链/分享**：`/explore?dim=region&node=156`、`?dim=industry&code=A` 可分享/回退。
9. **搜索体验**：全局搜索（名称/编码/英文/坐标）→ 定位地图 + 展开树 + 打开明细。
10. **治理融合**：标准层（UN 数据）**只读** + **本地 overlay**（S5）+ **AI 命令**（S6）**内嵌 Explorer**。
11. **移动端**：树→抽屉、地图手势；uni-app 可多端（H5 优先）。
12. **资源层（未来）**：`region × industry` 索引 → 地图点选即筛资源（商家/学校/服务），与订餐/AI 辅导/组织打通。
13. **导出**：Excel（xlsx）/ JSON 易；**PNG** 需 canvas 截图（地图/treemap）。
14. **埋点/分析**：哪些维度被浏览/搜索，反哺运营。

## 6. 决策点（需你拍板）

1. **首页形态**：首页 = **纯 explorer**（顶栏+地图+树/明细），还是 explorer **嵌在现有工作台**（卡片网格之上加一个维度入口）？
2. **几何策略**：默认**简化世界底图**（快）+ 放大加载细节，还是直接上完整 GeoJSON（重）？
3. **区域下钻**：是否需要 `maps`（省/市细分，23MB）？还是**先只到国家**（12MB）？
4. **皮肤**：并入 GRI 令牌（推荐）还是保留「域览」teal 原味？
5. **落位**：首页（portal `/`）改造，还是新 `/explore` 页 + 首页入口？
6. **首卡**：先由**我**搭 C1+C2 骨架出效果，还是**下达给 Claude/Codex**？
