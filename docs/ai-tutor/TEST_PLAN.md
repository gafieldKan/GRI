## 七、快速开始

### 开始测试

1. 启动后端服务
   ```bash
   cd /home/ubantu/GRI/services/ai-tutor-backend
   node src/index.js
   ```

2. 打开测试页面
   ```
   file:///home/ubantu/GRI/apps/web-ai-tutor/test.html
   ```

3. 点击"检查服务"按钮
4. 点击"创建会话"按钮
5. 点击"连接"按钮开始聊天测试
6. 点击"生成报告"查看测试结果

### 查看日志

所有操作日志都会在页面底部的"运行日志"区域显示，可以随时查看历史记录。
