## 申请步骤

### 步骤 1: 注册账号

1. 访问 https://www.oracle.com/cloud/free/
2. 点击 "Start for free" 按钮
3. 填写账号信息:
   - 邮箱地址
   - 手机号码
   - 所在国家/地区

### 步骤 2: 验证身份

1. 输入手机号码接收验证码
2. 填写信用卡信息进行验证（Visa/MasterCard）
   - 会预扣 $1 美元验证，随后退还
   - 不会被收取任何费用
3. 等待审核通过（通常几分钟内）

### 步骤 3: 创建实例

1. 登录 Oracle Cloud 控制台
2. 进入 "计算" -> "实例"
3. 点击 "创建实例"

**配置选择:**

```
名称：frp-server（可自定义）
映像：Ubuntu 22.04
区域：选择离你最近的

形状类型：更改形状
-> 选择 VM.Standard.A1.Flex (ARM)
-> OCPU: 4
-> 内存：24 GB
```

**网络配置:**
```
虚拟私有云：选择你的 VCN
子网：选择公有子网
```

**SSH 密钥:**
```
选择"上传 SSH 密钥文件"
上传你的公钥 (id_rsa.pub)
或生成新密钥对并下载私钥
```

### 步骤 4: 配置网络安全组

创建实例后，需要开放端口：

1. 进入 "网络" -> "虚拟云网络"
2. 点击你的 VCN
3. 点击 "安全列表"
4. 添加以下入站规则:

| 源 | 协议 | 端口范围 | 说明 |
|----|----|----|----|
| 0.0.0.0/0 | TCP | 7000 | frp 客户端连接 |
| 0.0.0.0/0 | TCP | 7500 | frps 管理面板 |
| 0.0.0.0/0 | TCP | 8080 | 隧道 HTTP 服务 |
| 0.0.0.0/0 | TCP | 8443 | 隧道 HTTPS 服务 |
| 0.0.0.0/0 | TCP | 22 | SSH 连接 |

### 步骤 5: 获取公网 IP

1. 进入 "实例" 列表
2. 点击你的实例名称
3. 记录 "公有 IP 地址"
4. 该 IP 将用于 frpc 配置

## SSH 连接

```bash
# Linux/macOS
ssh -i ~/.ssh/id_rsa ubuntu@YOUR_ORACLE_IP

# Windows (使用 PowerShell)
ssh -i C:\path\to\key.pem ubuntu@YOUR_ORACLE_IP
```

## 常见问题

### Q: 信用卡验证失败怎么办？
A: 确保持卡人姓名与账号一致，可尝试联系银行确认是否拦截了验证交易。

### Q: 免费额度会过期吗？
A: ARM 计算资源永久免费，但需要保持账号活跃（至少每 3 个月登录一次）。

### Q: 可以创建多个实例吗？
A: 免费账号最多可创建 4 个 ARM 实例，共享 4 核 24G 资源。

### Q: 流量超了怎么办？
A: 免费额度每月 1TB 出站流量，超出后按量计费。可在账单设置中配置使用量预警。
