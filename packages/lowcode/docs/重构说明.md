# GRI 低代码平台代码重构说明

## 一、重构概述

根据 GRI 全球资源整合平台的代码规范要求，对低代码平台核心模块进行了全面重构，确保所有代码遵循以下原则：

1. **面向对象设计**：封装、继承、多态
2. **GoF 设计模式**：工厂、策略、代理、装饰器等
3. **钩子扩展机制**：所有核心类预留钩子
4. **配置化优先**：所有可配置项通过配置中心管理
5. **全球化支持**：多语言、多时区、多货币

---

## 二、重构内容

### 2.1 新增基础类（BaseEntity.js）

**文件**: `lowcode/core/BaseEntity.js`

**内容**:
- `HookManager` - 钩子管理器，支持优先级排序
- `BaseEntity` - 基础实体类，提供封装性、生命周期钩子
- `ConfigurableEntity` - 可配置实体类，支持功能开关、分层配置

**特性**:
```javascript
// 使用示例
class Order extends ConfigurableEntity {
  constructor(config) {
    super(config)
  }

  // 钩子扩展
  on('beforeCreate', async (ctx) => {
    // 创建前逻辑
  })
}
```

---

### 2.2 重构模块管理器（ModuleManager.js）

**文件**: `lowcode/core/ModuleManager.js`

**设计模式应用**:
- **工厂模式**: `ModuleFactory` 创建模块实例
- **单例模式**: `moduleManager` 单例
- **观察者模式**: 继承 EventEmitter
- **封装性**: 私有字段使用 `#` 前缀

**主要类**:
```javascript
Module extends BaseEntity        // 模块实体
ModuleFactory                   // 工厂模式
ModuleManagerClass              // 管理器单例
```

**变更点**:
- 所有模块继承 `BaseEntity`
- 使用私有字段封装内部状态
- 添加完整的钩子系统
- 支持模块层级树结构

---

### 2.3 重构租户管理器（TenantManager.js）

**文件**: `lowcode/core/TenantManager.js`

**设计模式应用**:
- **策略模式**: `QuotaStrategy` 配额策略
- **工厂模式**: `TenantFactory` 创建租户
- **单例模式**: `tenantManager` 单例

**主要类**:
```javascript
Tenant extends ConfigurableEntity  // 租户实体（可配置）
TenantFactory                      // 工厂模式
BasicQuotaStrategy                 // 基础配额策略
EnterpriseQuotaStrategy            // 企业配额策略
```

**特性**:
- 继承 `ConfigurableEntity`，支持配置化
- 配额管理支持多种策略
- 完整的生命周期钩子

---

### 2.4 重构权限管理器（PermissionManager.js）

**文件**: `lowcode/core/PermissionManager.js`

**设计模式应用**:
- **策略模式**: `PermissionStrategy` 权限策略
- **责任链模式**: 多层权限检查
- **单例模式**: `permissionManager` 单例

**主要类**:
```javascript
Role extends BaseEntity                 // 角色实体
PermissionDescriptor                  // 权限描述符
ModelPermissionStrategy               // 模型权限策略
DataPermissionStrategy                // 数据权限策略
UserPermissionContext                 // 用户权限上下文
```

**特性**:
- 支持通配符权限匹配
- 角色继承
- 数据权限范围（本人/部门/全部）
- 权限缓存机制

---

### 2.5 新增配置服务（ConfigService.js）

**文件**: `lowcode/core/ConfigService.js`

**功能**:
- 分层配置（系统/租户/组织/用户）
- 功能开关（Feature Flags）
- 国际化（i18n）支持

**主要类**:
```javascript
ConfigServiceClass    // 配置服务单例
I18nServiceClass      // 国际化服务单例
ConfigItem           // 配置项实体
```

**特性**:
- 配置分层合并
- 条件功能开关
- 多语言翻译
- 数字/货币/日期格式化

## 四、钩子扩展点

所有核心类都提供了以下钩子：

### 4.1 通用钩子
- `beforeCreate` - 创建前
- `afterCreate` - 创建后
- `beforeUpdate` - 更新前
- `afterUpdate` - 更新后
- `beforeDelete` - 删除前
- `afterDelete` - 删除后

### 4.2 注册钩子方式

```javascript
import { moduleManager } from './core/ModuleManager.js'

// 方式一：链式调用
moduleManager
  .on('register', (ctx) => console.log('模块注册', ctx))
  .on('addApp', (ctx) => console.log('添加应用', ctx))

// 方式二：优先级
moduleManager.on('beforeSave', async (ctx) => {
  // 高优先级先执行
}, 10)
```

## 五、配置化示例

### 5.1 功能开关

```javascript
import { configService } from './core/ConfigService.js'

// 注册功能
configService.set('features.multiCurrency', {
  enabled: true,
  conditions: [
    { field: 'region', operator: 'in', value: ['CN', 'US', 'EU'] }
  ]
})

// 检查功能
if (configService.isEnabled('multiCurrency', { region: 'CN' })) {
  // 启用多币种功能
}
```

### 5.2 分层配置

```javascript
// 系统默认配置
configService.set('maxOrderAmount', 10000, 'system')

// 租户配置（覆盖系统）
configService.set('maxOrderAmount', 50000, 'tenant')

// 获取配置（自动合并）
const maxAmount = configService.get('maxOrderAmount') // 50000
```

## 六、国际化示例

```javascript
import { i18n } from './core/ConfigService.js'

// 加载翻译
i18n.loadTranslations('zh-CN', {
  'order.status.pending': '待支付',
  'order.status.paid': '已支付'
})

i18n.loadTranslations('en-US', {
  'order.status.pending': 'Pending',
  'order.status.paid': 'Paid'
})

// 设置语言
i18n.setLocale('zh-CN')

// 翻译
console.log(i18n.t('order.status.pending'))  // 待支付
console.log(i18n.t('order.status.paid'))     // 已支付

// 带参数翻译
i18n.t('order.amount', { amount: '100' })  // 订单金额：100

// 格式化
i18n.formatNumber(1234.56)           // 1,234.56
i18n.formatCurrency(1234.56, 'CNY')  // ¥1,234.56
i18n.formatDate(Date.now())          // 2026/05/14
```
