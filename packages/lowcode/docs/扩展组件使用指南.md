## 1. 电子签名组件

### 功能特性
- 支持手写签名
- Canvas 绘图实现
- 支持移动端触摸
- 可配置数字证书
- 合规签字手续

### 使用方式

```javascript
import { ElectronicSignature } from '@awesome-lowcode/components'

function ContractForm() {
  const handleSign = (signatureData) => {
    console.log('签名数据:', signatureData)
    // 保存签名图片数据
  }

  return (
    <ElectronicSignature
      title="合同签署"
      required={true}
      onSign={handleSign}
    />
  )
}
```

### 属性说明

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| title | string | '电子签名' | 标题 |
| required | boolean | false | 是否必填 |
| onSign | function | - | 签名完成回调 |
| value | string | - | 受控值（签名图片 URL） |
| disabled | boolean | false | 是否禁用 |

## 2. VR 展示组件

### 功能特性
- 360 度全景展示
- 支持热点标记
- 多图片切换
- 全屏查看
- 资源仿真展示

### 使用方式

```javascript
import { VRViewer } from '@awesome-lowcode/components'

function RestaurantDetail() {
  const images = [
    '/images/restaurant/panorama1.jpg',
    '/images/restaurant/panorama2.jpg'
  ]

  const hotspots = [
    {
      position: [0.3, 0.5],
      label: '灶台区',
      link: '/kitchen/1',
      icon: '🔥'
    }
  ]

  return (
    <VRViewer
      type="restaurant"
      images={images}
      hotspots={hotspots}
      onHotspotClick={(hotspot) => {
        console.log('点击热点:', hotspot)
      }}
    />
  )
}
```

### 属性说明

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| type | string | 'restaurant' | 类型：restaurant\|kitchen\|farm |
| images | array | [] | 全景图片列表 |
| hotspots | array | [] | 热点标记 |
| onHotspotClick | function | - | 热点点击回调 |

## 3. 地图组件

### 功能特性
- 支持高德/百度地图
- 标记点展示
- 配送范围绘制
- 路线规划

### 使用方式

```javascript
import { MapView } from '@awesome-lowcode/components'

function DeliveryMap() {
  const markers = [
    {
      lat: 39.9042,
      lng: 116.4074,
      title: '餐厅位置',
      description: '<div>朝阳路店</div>'
    }
  ]

  return (
    <MapView
      mapType="amap"
      apiKey="your_api_key"
      center={{ lat: 39.9042, lng: 116.4074 }}
      zoom={14}
      markers={markers}
      showDeliveryRange={true}
      deliveryRange={5}
    />
  )
}
```

### 属性说明

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| mapType | string | 'amap' | 地图类型：amap\|bmap |
| apiKey | string | '' | API Key |
| center | object | 北京坐标 | 地图中心点 |
| zoom | number | 12 | 缩放级别 |
| markers | array | [] | 标记点列表 |
| showDeliveryRange | boolean | false | 是否显示配送范围 |

## 4. 组织选择器组件

### 功能特性
- 树形结构展示
- 支持多层级组织
- 支持搜索过滤
- 支持单选/多选

### 使用方式

```javascript
import { OrganizationSelector } from '@awesome-lowcode/components'

function OrganizationForm() {
  const handleChange = (value) => {
    console.log('选择的组织:', value)
  }

  return (
    <OrganizationSelector
      placeholder="请选择组织"
      multiple={false}
      showSearch={true}
      onChange={handleChange}
    />
  )
}
```

### 属性说明

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| value | string | - | 选中值 |
| multiple | boolean | false | 是否多选 |
| placeholder | string | '请选择组织' | 占位文本 |
| showSearch | boolean | true | 是否显示搜索 |
| onChange | function | - | 选择变化回调 |

## 5. 资源选择器组件

### 功能特性
- 支持多种资源类型
- 带状态展示
- 图文展示
- 自定义数据源

### 使用方式

```javascript
import { ResourceSelector } from '@awesome-lowcode/components'

function ResourceForm() {
  const handleChange = (value) => {
    console.log('选择的资源:', value)
  }

  return (
    <ResourceSelector
      resourceType="restaurant"
      placeholder="请选择餐厅"
      showImage={true}
      onChange={handleChange}
    />
  )
}
```

### 属性说明

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| resourceType | string | 'restaurant' | 资源类型 |
| value | string | - | 选中值 |
| placeholder | string | '请选择资源' | 占位文本 |
| showImage | boolean | true | 是否显示图片 |
| onChange | function | - | 选择变化回调 |

## 6. 工作流状态机引擎

### 功能特性
- 状态机驱动
- 支持超时处理
- 事件驱动
- 生命周期钩子

### 使用方式

```javascript
import { stateMachineEngine, OrderStateMachine } from '@awesome-lowcode/engine'

// 注册状态机类型
stateMachineEngine.registerType('order', OrderStateMachine)

// 创建实例
const orderMachine = stateMachineEngine.create('order', {
  orderId: 'ORD001',
  userId: 'user_001'
})

// 状态转换
orderMachine.transition('paid')

// 监听状态变化
stateMachineEngine.on('stateChange', ({ from, to, context }) => {
  console.log(`状态变化：${from} -> ${to}`)
})
```

### 订单状态流转图

```
pending_payment → paid → confirmed → cooking → ready → delivering → completed
       ↓            ↓         ↓           ↓          ↓         ↓           ↓
   cancelled   cancelled  cancelled   cancelled  cancelled  cancelled   refunded
```
