## 1. 环境准备

### 1.1 系统要求

| 组件 | 最低版本 | 推荐版本 |
|------|---------|---------|
| Node.js | v18.0.0 | v20.x |
| npm | v8.0.0 | v10.x |
| 浏览器 | Chrome 90+ | Chrome 最新版 |
| 内存 | 4GB | 8GB+ |

### 1.2 检查环境

```bash
# 检查 Node.js 版本
node -v

# 检查 npm 版本
npm -v

# 如果版本过低，请升级
# Ubuntu/Debian: curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
# macOS: brew install node@20
# Windows: 访问 https://nodejs.org 下载安装
```

### 1.3 项目目录结构

```
awesome-lowcode/
├── src/                    # 前端源码
│   ├── App.jsx            # 主应用组件
│   ├── main.jsx           # 入口文件
│   ├── components/        # UI 组件
│   └── pages/             # 页面组件
├── lowcode/               # 低代码核心
│   ├── core/              # 核心模块
│   ├── engine/            # 引擎层
│   ├── components/        # 设计器组件

├── tests/                 # 测试文件
├── docs/                  # 文档
└── package.json           # 项目配置
```

## 2. 安装与部署

### 2.1 安装依赖

```bash
# 进入项目目录
cd /home/ubantu/reactProject/awesome-lowcode

# 安装所有依赖
npm install

# 如果安装失败，尝试清除缓存后重试
npm cache clean --force
npm install
```

### 2.2 环境变量配置（可选）

```bash
# 复制环境变量示例文件
cp .env.example .env

# 编辑环境变量（如需要）
vim .env
```

### 2.3 开发模式部署

```bash
# 启动开发服务器（默认端口 5173）
npm run dev

# 指定端口
npm run dev -- --port 3000

# 开放网络访问
npm run dev -- --host 0.0.0.0
```

### 2.4 生产模式部署

```bash
# 构建生产版本
npm run build

# 预览生产构建
npm run preview

# 部署到 Nginx（示例）
# 将 dist/ 目录内容部署到 Nginx 的 root 目录
```

### 2.5 Docker 部署（可选）

```bash
# 使用 Docker Compose 启动
docker-compose up -d

# 查看日志
docker-compose logs -f
```

## 7. 常见问题

### 7.1 安装问题

**问题**: `npm install` 失败

**解决**:
```bash
# 清除缓存
npm cache clean --force

# 删除 node_modules 重新安装
rm -rf node_modules package-lock.json
npm install

# 使用淘宝镜像
npm install --registry=https://registry.npmmirror.com
```

### 7.2 启动问题

**问题**: 端口被占用

**解决**:
```bash
# 更换端口
npm run dev -- --port 3000

# 或查找占用端口的进程
lsof -i :5173
kill -9 <PID>
```

### 7.3 构建问题

**问题**: `npm run build` 失败

**解决**:
```bash
# 检查 Node.js 版本
node -v  # 需要 v18+

# 升级 Vite 和相关依赖
npm update vite @vitejs/plugin-react

# 重新构建
npm run build
```

### 7.4 浏览器兼容性问题

**问题**: Chrome 版本过低

**解决**:
- 升级到最新版 Chrome
- 或使用 Edge/Firefox 最新版

### 7.5 内存不足

**问题**: 开发服务器内存溢出

**解决**:
```bash
# 增加 Node.js 内存限制
export NODE_OPTIONS="--max-old-space-size=4096"
npm run dev
```
