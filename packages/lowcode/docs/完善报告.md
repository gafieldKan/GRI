## 二、新增功能模块

| 农场 | farm | 农场/基地 |

**特性**:
- ✅ 支持多级组织架构（路径枚举法）
- ✅ 封装性：私有字段，getter/setter 访问
- ✅ 完整的生命周期钩子

### 2.3 角色与权限模型

**文件**: `lowcode/domain/organization/Role.js`

**核心类**:
- `Role` - 角色实体类

| 范围 | 代码 | 说明 |
|------|------|------|
| 系统级 | system | 全部数据 |

## 五、使用示例

### 5.1 创建组织

```javascript
import { Organization, OrganizationType } from './lowcode/domain/organization/Organization.js'

const org = new Organization({
  name: '朝阳路店',
  shortName: '朝阳店',
  type: OrganizationType.STORE,
  parentId: 'org_bj_branch',
  parentPath: '/org_root/org_bj_branch',
  level: 3,
  industry: '5610'  // ISIC 餐饮业代码
})

// 验证
const validation = org.validate()
if (validation.valid) {
  console.log('组织信息有效')
} else {
  console.error(validation.errors)
}

// 应用业务规则
org.applyBusinessRules()
```

### 5.2 添加组织成员

```javascript
import { OrganizationMember, MemberRole } from './lowcode/domain/organization/OrganizationMember.js'

const member = new OrganizationMember({
  organizationId: 'org_store_001',
  userId: 'user_001',
  role: MemberRole.MANAGER,
  title: '店长',
  employeeNo: 'EMP001'
})

// 激活成员
member.activate()
```

### 5.3 创建角色并分配权限

```javascript
import { Role, PermissionDescriptor, DataScope } from './lowcode/domain/organization/Role.js'

const role = new Role({
  name: '餐厅管理员',
  code: 'RESTAURANT_ADMIN',
  type: 'organization',
  dataScope: DataScope.DEPT
})

// 添加权限
role.addPermission(new PermissionDescriptor('restaurant', 'create', DataScope.DEPT))
role.addPermission(new PermissionDescriptor('dish', '*', 'dept'))
role.addPermission(new PermissionDescriptor('order', 'read', 'dept'))

// 检查权限
if (role.hasPermission('restaurant', 'create')) {
  console.log('有创建餐厅的权限')
}
```

### 5.4 使用角色模板

```javascript
import { RoleFactory, RoleTemplates } from './lowcode/domain/organization/Role.js'

// 从模板创建角色
const adminRole = RoleFactory.fromTemplate('ORG_MANAGER')

// 自定义角色
const customRole = RoleFactory.createCustom(
  '自定义角色',
  'CUSTOM_ROLE',
  ['restaurant:read:self', 'order:create:self'],
  DataScope.SELF
)
```
