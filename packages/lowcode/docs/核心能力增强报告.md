## 二、能力详细说明

### 1. 表达式引擎 (ExpressionEngine)

**能力描述**: 轻量级表达式计算引擎，支持变量解析、函数计算、条件表达式

**核心功能**:
- 变量解析：`{{ user.name }}`
- 算术运算：`{{ 1 + 2 * 3 }}`
- 条件表达式：`{{ status === "active" ? "启用" : "禁用" }}`
- 函数调用：`{{ formatDate(order.date, "YYYY-MM-DD") }}`
- 数据绑定：支持双向绑定

**内置函数**:
- 数学函数：`abs`, `round`, `floor`, `ceil`, `min`, `max`, `pow`, `sqrt`, `random`
- 字符串函数：`length`, `trim`, `substr`, `slice`, `split`, `join`, `replace`
- 逻辑函数：`if`, `and`, `or`, `not`, `eq`, `ne`, `gt`, `lt`, `gte`, `lte`
- 类型判断：`isString`, `isNumber`, `isBoolean`, `isArray`, `isObject`
- 类型转换：`toString`, `toNumber`, `toBoolean`, `toArray`
- 数组函数：`concat`, `reverse`, `filter`, `map`, `sort`, `find`, `some`, `every`

**使用示例**:
```javascript
import { expressionEngine } from 'lowcode'

// 计算表达式
const result = expressionEngine.evaluate('{{ order.price * order.quantity }}', {
  order: { price: 100, quantity: 3 }
})
// result: 300

// 条件表达式
const status = expressionEngine.evaluate('{{ status === "active" ? "启用" : "禁用" }}', {
  status: 'active'
})
// status: "启用"

// 注册自定义函数
expressionEngine.registerFunction('formatCurrency', (value) => {
  return `¥${Number(value).toFixed(2)}`
})
```

### 2. 数据源管理 (DataSourceManager)

**能力描述**: 统一管理多种数据源，支持 REST、GraphQL、MySQL、PostgreSQL、MongoDB 等

**支持的数据源类型**:
- REST API
- GraphQL
- MySQL
- PostgreSQL
- MongoDB
- SQLite
- Oracle
- SQL Server

**核心功能**:
- 数据源注册与配置
- 连接测试与管理
- 数据源适配器模式
- 请求/响应转换器

**使用示例**:
```javascript
import { dataSourceManager, DataSourceType } from 'lowcode'

// 注册 REST 数据源
dataSourceManager.register({
  id: 'external_api',
  name: '外部 API',
  type: DataSourceType.REST,
  config: {
    baseURL: 'https://api.example.com',
    headers: {
      'Authorization': 'Bearer token'
    }
  },
  endpoints: {
    getUsers: { method: 'GET', path: '/users' },
    createUser: { method: 'POST', path: '/users' }
  }
})

// 连接数据源
await dataSourceManager.connect('external_api')

// 执行查询
const users = await dataSourceManager.execute('external_api', 'getUsers')
```

### 3. 自动 API 生成 (ApiGenerator)

**能力描述**: 基于模型 Schema 自动生成 CRUD REST API

**核心功能**:
- 自动生成 CRUD 接口
- 支持分页、排序、过滤
- 支持批量操作
- 数据验证集成
- 中间件支持

**生成的 API 路由**:
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/:model` | 列表查询（支持分页/过滤/排序） |
| GET | `/api/:model/:id` | 获取详情 |
| POST | `/api/:model` | 创建 |
| PUT | `/api/:model/:id` | 更新 |
| DELETE | `/api/:model/:id` | 删除 |
| POST | `/api/:model/bulk` | 批量操作 |

**使用示例**:
```javascript
import { apiGenerator, schemaManager } from 'lowcode'

// 注册模型
schemaManager.registerModel('Order', {
  fields: [
    { name: 'orderNo', type: 'string', required: true },
    { name: 'amount', type: 'number', required: true },
    { name: 'status', type: 'select', options: ['pending', 'paid', 'shipped'] }
  ]
})

// 生成 API
apiGenerator.generate('Order', schemaManager.getModel('Order'))

// 添加中间件
apiGenerator.use(async (context) => {
  // 权限检查
  if (!context.user) {
    throw new Error('未授权')
  }
})
```

### 4. 国际化系统 (I18nManager)

**能力描述**: 完整的多语言支持，包括语言包管理、翻译管理、运行时切换

**核心功能**:
- 多语言包管理
- 翻译键值管理
- 运行时语言切换
- 缺失翻译警告
- 参数化翻译

**支持的语言**:
- 简体中文 (zh-CN)
- 英文 (en-US)
- 繁体中文 (zh-TW)
- 日语 (ja-JP)
- 韩语 (ko-KR)

**使用示例**:
```javascript
import { i18nManager, t } from 'lowcode'

// 翻译文本
const saveText = t('common.save') // "保存"

// 带参数的翻译
const message = i18nManager.t('order.total', { count: 5, total: 100 })
// "共 5 条，总计 100 元"

// 切换语言
i18nManager.setLocale('en-US')

// 注册新语言包
i18nManager.registerPack('ja-JP', '日本語', {
  'common.save': '保存',
  'common.cancel': 'キャンセル'
})
```

### 5. 版本管理 (VersionManager)

**能力描述**: 实现页面/模型/配置的版本快照、差异对比、回滚功能

**核心功能**:
- 版本快照
- 版本历史
- 差异对比
- 版本回滚
- 版本标签
- 版本发布/归档

**版本状态**:
- `draft`: 草稿
- `published`: 已发布
- `archived`: 已归档
- `rolledback`: 已回滚

**使用示例**:
```javascript
import { versionManager, EntityType } from 'lowcode'

// 创建快照
versionManager.snapshot(
  EntityType.PAGE,
  'order-list',
  pageData,
  { name: '添加金额字段', createdBy: 'admin' }
)

// 获取版本历史
const history = versionManager.getHistory(EntityType.PAGE, 'order-list')

// 比较版本
const diff = versionManager.compare('v1', 'v2')

// 回滚
await versionManager.rollback('v1', pageData)
```

### 6. 主题定制 (ThemeManager)

**能力描述**: Design Token 系统，支持主题配置中心

**核心功能**:
- Design Token 管理
- 预设主题（深色模式、紧凑模式）
- 主题变量 CSS 生成
- 主题切换
- 自定义主题

**Token 分类**:
- 颜色（主色、成功色、警告色、错误色）
- 圆角（xs ~ xl）
- 间距（xs ~ xxl）
- 字体（字号、字重、行高）
- 阴影（sm ~ lg）
- 动效（时长、缓动）

**使用示例**:
```javascript
import { themeManager } from 'lowcode'

// 切换深色模式
themeManager.setTheme('dark')

// 获取 Token 值
const primaryColor = themeManager.getCurrentTheme().getToken('colors.primary')

// 注册自定义主题
themeManager.register({
  id: 'enterprise',
  name: '企业主题',
  tokens: {
    colors: { primary: '#1890ff' }
  }
})
```

### 7. 页面路由管理 (RouteManager)

**能力描述**: 页面树管理、路由配置、菜单自动生成

**核心功能**:
- 页面注册与管理
- 页面树形结构
- 动态路由匹配
- 菜单生成（带权限过滤）
- 路由参数解析

**页面类型**:
- `page`: 普通页面
- `folder`: 文件夹/分组
- `link`: 外链
- `iframe`: iframe 页面

**使用示例**:
```javascript
import { routeManager, PageType } from 'lowcode'

// 注册页面
routeManager.register({
  name: '订单管理',
  path: '/orders',
  component: 'OrderList',
  permission: 'order:list',
  icon: 'ordered-list'
})

// 获取页面树
const tree = routeManager.getPageTree()

// 生成菜单（带权限过滤）
const menu = routeManager.generateMenu(userId, userRoles)

// 匹配路由
const matched = routeManager.matchRoute('/orders/123')
```

### 8. 逻辑编排引擎 (LogicEngine)

**能力描述**: 可视化业务逻辑编排，支持条件/循环/变量/动作

**节点类型**:
- `trigger`: 触发器（入口节点）
- `action`: 执行动作
- `condition`: 条件判断
- `loop`: 循环
- `variable`: 变量操作
- `delay`: 延迟
- `script`: 脚本执行

**内置动作**:
- `log`: 日志输出
- `http`: HTTP 请求
- `notification`: 通知

**使用示例**:
```javascript
import { logicEngine, LogicNodeType } from 'lowcode'

// 注册逻辑流
logicEngine.registerFlow({
  id: 'order-approval',
  name: '订单审批流程',
  nodes: [
    { id: 'start', name: '开始', type: LogicNodeType.TRIGGER },
    { id: 'check', name: '金额检查', type: LogicNodeType.CONDITION, config: {
      condition: '{{ amount > 1000 }}'
    }},
    { id: 'approve', name: '审批', type: LogicNodeType.ACTION, config: {
      actionType: 'approval'
    }},
  ],
  edges: [
    { source: 'start', target: 'check' },
    { source: 'check', target: 'approve', condition: 'true' },
  ]
})

// 执行流程
const result = await logicEngine.executeFlow('order-approval', {
  orderId: '123',
  amount: 1500
})
```

## 四、使用指南

### 从现有代码迁移

```javascript
// 之前
import { workflowEngine } from 'lowcode'

// 现在 - 所有新能力都可用
import {
  expressionEngine,      // 表达式引擎
  dataSourceManager,     // 数据源管理
  apiGenerator,          // 自动 API 生成
  i18nManager,           // 国际化
  versionManager,        // 版本管理
  themeManager,          // 主题定制
  routeManager,          // 路由管理
  logicEngine,           // 逻辑编排
  workflowEngine,        // 原有工作流
  eventEngine,           // 原有事件引擎
} from 'lowcode'
```

### 完整示例：订单管理应用

```javascript
import {
  schemaManager,
  apiGenerator,
  i18nManager,
  themeManager,
  routeManager,
  logicEngine,
  LogicNodeType,
} from 'lowcode'

// 1. 设置主题
themeManager.setTheme('default')

// 2. 设置语言
i18nManager.setLocale('zh-CN')

// 3. 定义数据模型
schemaManager.registerModel('Order', {
  fields: [
    { name: 'orderNo', type: 'string', label: '订单号', required: true },
    { name: 'customer', type: 'string', label: '客户', required: true },
    { name: 'amount', type: 'number', label: '金额', required: true },
    { name: 'status', type: 'select', label: '状态', options: ['pending', 'paid', 'shipped'] }
  ]
})

// 4. 生成 API
apiGenerator.generate('Order', schemaManager.getModel('Order'))

// 5. 注册页面
routeManager.register({
  name: '订单列表',
  path: '/orders',
  component: 'OrderList',
  permission: 'order:list'
})

// 6. 定义审批流程
logicEngine.registerFlow({
  id: 'order-approval',
  name: '订单审批流程',
  nodes: [
    { id: 'start', name: '开始', type: LogicNodeType.TRIGGER },
    { id: 'check', name: '大额检查', type: LogicNodeType.CONDITION, config: {
      condition: '{{ amount > 1000 }}'
    }},
    { id: 'manager', name: '经理审批', type: LogicNodeType.ACTION, config: {
      actionType: 'approval',
      approver: 'manager'
    }},
    { id: 'auto', name: '自动通过', type: LogicNodeType.ACTION, config: {
      actionType: 'approve'
    }},
  ],
  edges: [
    { source: 'start', target: 'check' },
    { source: 'check', target: 'manager', condition: 'true' },
    { source: 'check', target: 'auto', condition: 'false' },
  ]
})
```
