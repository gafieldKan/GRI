## 五、钩子扩展点清单

### 5.1 通用钩子（所有实体）

| 钩子名称 | 触发时机 | 用途 |
|---------|---------|------|
| `beforeCreate` | 创建前 | 数据校验、预处理 |
| `afterCreate` | 创建后 | 通知、索引更新 |
| `beforeUpdate` | 更新前 | 数据校验、审计 |
| `afterUpdate` | 更新后 | 缓存失效、通知 |
| `beforeDelete` | 删除前 | 关联检查、备份 |
| `afterDelete` | 删除后 | 清理关联、日志 |

### 5.2 模块特定钩子

| 钩子名称 | 触发时机 |
|---------|---------|
| `afterAddChild` | 添加子模块后 |
| `afterRemoveChild` | 移除子模块后 |
| `afterAddApp` | 添加应用后 |
| `afterRemoveApp` | 移除应用后 |

### 5.3 租户特定钩子

| 钩子名称 | 触发时机 |
|---------|---------|
| `afterActivate` | 激活租户后 |
| `afterSuspend` | 暂停租户后 |
| `afterArchive` | 归档租户后 |
| `beforeCreateTenant` | 创建租户前 |
| `afterCreateTenant` | 创建租户后 |

## 十、使用示例

### 10.1 创建自定义实体

```javascript
import { BaseEntity } from './core/BaseEntity.js'
import { moduleManager } from './core/ModuleManager.js'

class Order extends BaseEntity {
  constructor(config) {
    super(config)
    this._orderNo = config.orderNo
    this._status = config.status || 'pending'
  }

  // 钩子：创建后处理
  async create(context) {
    await this.triggerHook('beforeCreate', { order: this, context })
    // 创建逻辑
    await this.triggerHook('afterCreate', { order: this, context })
    return this
  }
}
```
