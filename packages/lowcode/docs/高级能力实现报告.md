# 低代码平台高阶能力实现报告

## 概述

本文档记录了低代码平台缺失的 5 项高阶能力的完整实现，这些能力使平台能够对标行业头部产品（宜搭/简道云/PowerApps）。

## 实现清单

### 1. 可视化逻辑编排引擎 (Logic Flow Engine)

**文件位置**: `lowcode/engine/LogicFlowEngine.js`

**核心功能**:
- 支持节点拖拽、流程编排
- 条件分支、变量处理
- 多种节点类型（start/end/condition/action/script/apiCall/subFlow/loop）
- 流程验证与错误处理
- 流程实例管理

**关键类/接口**:
| 类名 | 说明 |
|------|------|
| FlowNode | 流程节点类 |
| FlowEdge | 流程连接线类 |
| FlowDefinition | 流程定义类 |
| FlowInstance | 流程实例类 |
| LogicFlowEngine | 逻辑流引擎主类 |

**使用示例**:
```javascript
import { logicFlowEngine } from 'lowcode/engine/LogicFlowEngine'

// 注册流程
logicFlowEngine.registerFlow({
  id: 'approval_flow',
  name: '审批流程',
  nodes: [
    { id: 'start', type: 'start' },
    { id: 'condition', type: 'condition', config: { conditions: [...] } },
    { id: 'approve', type: 'approval' },
    { id: 'end', type: 'end' },
  ],
  edges: [...]
})

// 启动流程
const instance = await logicFlowEngine.startFlow('approval_flow', context)
```

### 2. 高级工作流引擎（会签/或签/子流程）

**文件位置**: `lowcode/engine/AdvancedWorkflow.js`

**核心功能**:
- 会签（Countersign）：支持全部通过、百分比通过、指定数量通过
- 或签（Or Sign）：一人同意即可
- 票签（Vote）：按比例/票数决定
- 子流程（SubFlow）：支持嵌套流程
- 超时处理：自动同意/拒绝、升级处理、通知
- 任务管理：转办、委托、撤回

**关键类/接口**:
| 类名 | 说明 |
|------|------|
| ApprovalType | 审批类型枚举 |
| CountersignConfig | 会签配置类 |
| TaskInstance | 任务实例类 |
| WorkflowInstance | 工作流实例类 |
| AdvancedWorkflowEngine | 高级工作流引擎 |

**会签类型说明**:
| 类型 | 说明 | 判断逻辑 |
|------|------|----------|
| all | 全部通过 | 所有人同意且无人拒绝 |
| percentage | 百分比通过 | 同意比例 >= 设定百分比 |
| number | 指定数量 | 同意人数 >= 最小数量 |

**使用示例**:
```javascript
import { advancedWorkflowEngine, ApprovalType, CountersignConfig } from 'lowcode/engine/AdvancedWorkflow'

// 注册带会签的工作流
advancedWorkflowEngine.registerWorkflow({
  id: 'countersign_flow',
  name: '会签审批流',
  nodes: [{
    id: 'approval',
    type: 'approval',
    config: {
      approvalType: ApprovalType.COUNTERSIGN,
      countersignConfig: { type: 'percentage', percentage: 80 }
    }
  }]
})

// 审批任务
await advancedWorkflowEngine.approveTask(instanceId, taskId, userId, '同意')
```

### 3. 版本管理与回滚

**文件位置**: `lowcode/engine/VersionManager.js` (已存在，增强功能)

**核心功能**:
- 版本快照创建
- 版本历史管理
- 版本比较（差异对比）
- 版本回滚
- 发布/归档管理
- 自动保存（可选）

**关键类/接口**:
| 类名 | 说明 |
|------|------|
| Version | 版本类 |
| VersionSnapshot | 版本快照类 |
| VersionChain | 版本链类 |
| DiffUtil | 差异比较工具 |
| VersionManager | 版本管理器 |

**版本状态流转**:
```
draft -> published -> archived
           |
           v
       rolled_back
```

**使用示例**:
```javascript
import { versionManager, VersionType } from 'lowcode/engine/VersionManager'

// 创建版本快照
const snapshot = versionManager.createVersion({
  resourceType: 'model',
  resourceId: 'user_model',
  snapshotData: { ... },
  type: VersionType.MANUAL,
  description: '添加新字段'
})

// 发布版本
versionManager.publishVersion('model', 'user_model', snapshot.id)

// 回滚到历史版本
versionManager.restoreToVersion('model', 'user_model', targetVersionId)

// 比较版本差异
const diff = versionManager.compareVersions('model', 'user_model', v1, v2)
```

### 4. 多端适配预览

**文件位置**:
- `lowcode/components/MultiPlatformPreview/MultiPlatformPreview.jsx` (React 组件)
- `lowcode/engine/ResponsiveEngine.js` (响应式引擎，已存在)

**核心功能**:
- 支持多种设备类型预览（手机/平板/桌面/宽屏）
- 横屏/竖屏切换
- 缩放控制
- 网格辅助线
- 断点检测
- 响应式样式生成

**支持的设备类型**:
| 设备 | 宽度 | 高度 | 断点 |
|------|------|------|------|
| Mobile | 375px | 812px | mobile |
| Tablet | 768px | 1024px | tablet |
| Desktop | 1440px | 900px | desktop |
| Widescreen | 1920px | 1080px | widescreen |

**断点配置**:
```javascript
export const BREAKPOINTS = {
  xs: { min: 0, max: 575 },    // < 576px
  sm: { min: 576, max: 767 },  // >= 576px
  md: { min: 768, max: 991 },  // >= 768px
  lg: { min: 992, max: 1199 }, // >= 992px
  xl: { min: 1200, max: 1599 },// >= 1200px
  xxl: { min: 1600, max: Infinity }, // >= 1600px
}
```

**使用示例**:
```javascript
import { MultiPlatformPreview, useMultiPlatformPreview } from 'lowcode/components/MultiPlatformPreview'

// React 组件方式
function App() {
  return (
    <MultiPlatformPreview defaultDevice="desktop">
      <YourForm />
    </MultiPlatformPreview>
  )
}

// Hook 方式
function YourComponent() {
  const { currentDevice, deviceInfo } = useMultiPlatformPreview()
  return <div>{deviceInfo.name}</div>
}
```

### 5. 数据权限行级控制

**文件位置**: `lowcode/core/DataPermission.js`

**核心功能**:
- 行级权限控制（数据范围）
- 字段级权限控制
- 数据脱敏（手机号、邮箱、身份证等）
- 多租户数据隔离
- 角色权限继承

**数据范围类型**:
| 范围 | 说明 | 适用场景 |
|------|------|----------|
| ALL | 全部数据 | 管理员 |
| MINE | 仅本人数据 | 普通员工 |
| DEPT | 本部门数据 | 部门经理 |
| DEPT_AND_SUB | 本部门及子部门 | 大区经理 |
| CUSTOM | 自定义范围 | 特殊业务 |

**脱敏规则**:
| 类型 | 说明 | 示例 |
|------|------|------|
| PHONE | 手机号脱敏 | 138****5678 |
| EMAIL | 邮箱脱敏 | te**@example.com |
| NAME | 姓名脱敏 | 张** |
| ID_CARD | 身份证脱敏 | 110101********1234 |
| BANK_CARD | 银行卡脱敏 | 6222 **** **** 1234 |

**关键类/接口**:
| 类名 | 说明 |
|------|------|
| DataScope | 数据范围枚举 |
| MaskRule | 脱敏规则类 |
| RowPermissionRule | 行级权限规则类 |
| FieldPermissionConfig | 字段权限配置类 |
| DataPermissionManager | 数据权限管理器 |

**使用示例**:
```javascript
import {
  dataPermissionManager,
  DataScope,
  MaskType,
  RowPermissionRule,
  FieldPermissionConfig,
} from 'lowcode/core/DataPermission'

// 注册行级权限规则
dataPermissionManager.registerRowRule({
  model: 'order',
  name: '订单数据权限',
  scope: DataScope.DEPT_AND_SUB,
  roles: ['manager'],
})

// 注册字段权限
dataPermissionManager.registerFieldPermission({
  model: 'user',
  field: 'phone',
  permissionLevel: FieldPermissionLevel.VISIBLE,
  maskRule: { type: MaskType.PHONE },
  roles: ['admin'],
})

// 生成查询条件
const filter = dataPermissionManager.getRowFilter('order', user, role)

// 数据脱敏
const maskedData = dataPermissionManager.maskData('user', userData, user, role)
```
