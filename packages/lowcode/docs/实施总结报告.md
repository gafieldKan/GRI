## 二、核心功能详解

### 2.1 运行时渲染引擎

**功能特性**:
- ✅ 基于 JSON Schema 动态渲染
- ✅ 支持 15+ 内置组件类型
- ✅ 数据绑定与双向绑定
- ✅ 表达式解析（`${}` 和 `{{}}` 语法）
- ✅ 页面实例管理
- ✅ 序列化/反序列化

**使用示例**:
```javascript
import { renderEngine } from 'lowcode'

// 创建页面实例
const instance = renderEngine.createPageInstance('order-form', schema, {
  orderNo: 'ORD001',
  amount: 1000
})

// 数据绑定（双向）
renderEngine.updatePageData('order-form', 'amount', 2000)

// 渲染组件树
const rendered = renderEngine.renderTree(schema, {
  data: instance.binding.data
})
```

---

### 2.2 API 连接器

**功能特性**:
- ✅ REST/SOAP/GraphQL 协议支持
- ✅ 多种认证方式（Basic、Bearer、API Key、JWT、OAuth2）
- ✅ 请求/响应转换器
- ✅ 连接测试功能
- ✅ 缓存机制
- ✅ 端点管理

**使用示例**:
```javascript
import { apiConnector, ApiType, AuthType } from 'lowcode'

// 注册 API
apiConnector.register({
  id: 'external_api',
  name: '外部系统 API',
  type: ApiType.REST,
  baseUrl: 'https://api.example.com',
  auth: { type: AuthType.BEARER, token: 'your-token' },
  endpoints: [
    { id: 'get_users', name: '获取用户列表', method: 'GET', path: '/users' }
  ]
})

// 执行调用
const users = await apiConnector.execute('external_api', 'get_users')
```

---

### 2.3 数据库驱动

**功能特性**:
- ✅ MySQL 驱动
- ✅ PostgreSQL 驱动
- ✅ SQLite 驱动
- ✅ 查询构建器
- ✅ 连接池管理
- ✅ 表结构查询

**使用示例**:
```javascript
import { databaseManager, DatabaseType } from 'lowcode'

// 注册数据库
databaseManager.register({
  id: 'main_db',
  type: DatabaseType.MYSQL,
  host: 'localhost',
  port: 3306,
  database: 'myapp',
  username: 'root',
  password: 'password'
})

// 查询
const users = await databaseManager.query('main_db', 'SELECT * FROM users')

// 查询构建器
const result = await databaseManager
  .table('main_db', 'users')
  .whereEq('status', 'active')
  .orderBy('created_at', 'DESC')
  .limit(10)
  .execute()
```

---

### 2.4 可视化逻辑编排器

**功能特性**:
- ✅ 7 种节点类型（触发器、动作、条件、循环、变量、延迟、脚本）
- ✅ 拖拽式添加节点
- ✅ 节点连线（流程图）
- ✅ 属性配置面板
- ✅ 流程保存/加载
- ✅ 内置 6 种动作类型

**节点类型**:
| 类型 | 图标 | 说明 |
|------|------|------|
| 触发器 | ⚡ | 流程开始触发 |
| 执行动作 | 🔧 | 执行一个动作 |
| 条件判断 | ❓ | 条件分支判断 |
| 循环 | 🔄 | 循环执行 |
| 变量操作 | 📝 | 设置/获取变量 |
| 延迟 | ⏱ | 延迟执行 |
| 脚本 | 📜 | 执行自定义脚本 |

**使用示例**:
```jsx
import LogicFlowEditor from 'lowcode/components/LogicFlowEditor'

function App() {
  return (
    <LogicFlowEditor
      flowId="order-approval"
      onChange={(flow) => console.log('流程已保存:', flow)}
    />
  )
}
```

## 四、使用指南

### 4.1 快速开始

```javascript
import {
  renderEngine,      // 运行时渲染
  apiConnector,      // API 连接
  databaseManager,   // 数据库连接
  logicEngine,       // 逻辑编排
  expressionEngine,  // 表达式解析
} from 'lowcode'

// 1. 连接数据库
databaseManager.register({
  id: 'main_db',
  type: 'mysql',
  host: 'localhost',
  database: 'myapp'
})

// 2. 注册 API
apiConnector.register({
  id: 'external_api',
  type: 'rest',
  baseUrl: 'https://api.example.com'
})

// 3. 创建页面
const instance = renderEngine.createPageInstance('my-page', schema)

// 4. 执行逻辑流
logicEngine.executeFlow('my-flow', { data: instance.binding.data })
```

### 4.2 组件使用

```jsx
import { DataSourceForm, DataSourceList } from 'lowcode/components/DataSourceConfig'
import LogicFlowEditor from 'lowcode/components/LogicFlowEditor'

function App() {
  return (
    <div>
      <DataSourceList />
      <DataSourceForm dataSourceId="ds_1" />
      <LogicFlowEditor flowId="flow_1" />
    </div>
  )
}
```
