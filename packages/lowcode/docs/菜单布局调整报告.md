## 二、调整原则

### 2.1 功能聚合

将相关联的功能聚合到同一菜单下：
- **AI 功能拆分**: AI 助手和 AI 生成功能移至「应用中心」，AI 配置移至「系统设置」
- **应用市场整合**: 应用市场和示例应用合并到「应用中心」
- **发布流程整合**: 多端发布、版本管理、部署配置保持独立菜单

### 2.2 命名直观

- 「设计」→「设计中心」- 更明确
- 「数据」→「数据管理」- 更专业
- 「分析」→「分析洞察」- 更直观
- 「协同」→「协同办公」- 更清晰
- 「设置」→「系统设置」- 更准确

### 2.3 用户体验优先

- 高频功能前置（设计中心、数据管理）
- 低频功能后置（系统设置）
- 相关功能就近放置

## 三、菜单详细说明

### 3.1 设计中心
**包含功能**:
- 表单设计器 - 拖拽式表单构建
- 模型设计器 - 数据模型定义
- 工作流设计器 - 业务流程编排
- 逻辑流编排 - 业务逻辑可视化

**使用场景**: 页面和流程设计阶段

### 3.2 数据管理
**包含功能**:
- 数据源管理 - 多数据源配置
- API 连接器 - REST/SOAP/GraphQL 连接
- 模板库 - 表单/页面模板

**使用场景**: 数据源连接和模板管理

### 3.3 应用中心
**包含功能**:
- 应用市场 - 浏览和安装应用模板
- GRI 点餐系统 - 示例应用
- AI 助手 - 智能助手
- AI 生成 - AI 智能生成

**使用场景**: 获取应用模板和使用 AI 工具

### 3.4 分析洞察
**包含功能**:
- 数据分析 - 数据看板
- 性能监控 - 性能分析

**使用场景**: 数据分析和性能监控

### 3.5 协同办公
**包含功能**:
- 实时协作 - 多人协同编辑
- 评论批注 - 评论功能
- 消息通知 - 系统通知

**使用场景**: 团队协作和沟通

### 3.6 发布部署
**包含功能**:
- 多端发布 - 发布到多平台
- 版本管理 - Git 版本控制
- 部署配置 - 部署设置

**使用场景**: 应用发布和部署

### 3.7 系统设置
**包含功能**:
- 单点登录 (SSO) - 企业登录配置
- 权限管理 - RBAC 权限配置
- 插件管理 - 插件启用/禁用
- 系统配置 - 基础设置
- 帮助中心 - 文档和教程
- AI 配置 - AI 服务配置

**使用场景**: 系统管理和配置
