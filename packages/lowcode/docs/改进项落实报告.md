## 一、改进项清单

### 1. 统一私有字段风格 ✅

**问题描述**: 部分类（如 Tenant）的私有字段 `#` 与受保护字段 `_name` 混用，风格不统一。

**改进措施**:
1. 重构 `BaseEntity.js`，所有字段统一使用私有 `#` 前缀
2. 重构 `HookManager` 使用私有字段
3. 提供统一的 Getter/Setter 访问

**改进前**:
```javascript
export class BaseEntity {
  #internalState = {}  // 私有
  #accessLog = []      // 私有
  #metadata = {}       // 私有
  _id = ''             // 受保护（不一致）
  _status = ''         // 受保护（不一致）
}
```

**改进后**:
```javascript
export class BaseEntity {
  #id = ''             // 统一私有
  #createdAt = 0       // 统一私有
  #updatedAt = 0       // 统一私有
  #status = ''         // 统一私有
  #metadata = {}       // 统一私有
  #hookManager = null  // 统一私有

  // Getter/Setter 受控访问
  get id() { return this.#id }
  get status() { return this.#status }
  set status(value) { /* 钩子触发 */ }
}
```

**文件变更**:
- `lowcode/core/BaseEntity.js` - 完全重构
- `lowcode/core/HookManager` - 使用私有字段

### 2. 完善异常处理 ✅

**问题描述**: 部分方法静默失败，不抛出异常，导致问题难以排查。

**改进措施**:
1. 创建 `ValidationError` 统一异常类型
2. 所有关键方法添加参数验证
3. 插件不存在、类型错误等情况抛出明确异常

**改进前**:
```javascript
// PluginRegistry.js
async destroy(name) {
  const plugin = this.plugins.get(name)
  if (!plugin) {
    return  // 静默失败
  }
  // ...
}
```

**改进后**:
```javascript
// PluginRegistry.js
async destroy(name) {
  const plugin = this.plugins.get(name)
  if (!plugin) {
    throw new ValidationError(
      'name',
      'valid plugin name',
      name,
      `插件不存在：${name}`
    )
  }
  // ...
}
```

**异常类型覆盖**:
- 参数验证失败
- 插件不存在
- 插件初始化失败
- 插件加载失败
- 插件保存失败
- 插件销毁失败
- 插件激活失败
- 插件停用失败

**文件变更**:
- `lowcode/core/PluginRegistry.js` - 完善异常处理
- `lowcode/core/TypeValidator.js` - 新增异常类

### 3. 添加类型验证 ✅

**问题描述**: 缺少运行时类型验证，传入错误类型时导致隐式转换或运行时错误。

**改进措施**:
1. 创建 `TypeValidator` 工具类
2. 提供常用类型验证方法
3. 在构造函数和关键方法中添加类型验证

**新增工具类**:
```javascript
// TypeValidator.js
export class TypeValidator {
  static validateString(value, fieldName) { }
  static validateNumber(value, fieldName) { }
  static validateBoolean(value, fieldName) { }
  static validateFunction(value, fieldName) { }
  static validateObject(value, fieldName) { }
  static validateArray(value, fieldName) { }
  static validateId(value, fieldName) { }
  static validateEnum(value, enumObj, fieldName) { }
  static validateEmail(value, fieldName) { }
  static validatePhone(value, fieldName) { }
  static validateUrl(value, fieldName) { }
  static validateStringLength(value, min, max, fieldName) { }
  static validateNumberRange(value, min, max, fieldName) { }
  static validateArrayElements(arr, elementType, fieldName) { }
  static validateObjectShape(obj, schema, fieldName) { }
}
```

**使用示例**:
```javascript
// BaseEntity.js
constructor(config = {}) {
  // 参数验证
  if (config !== undefined && typeof config !== 'object') {
    throw new ValidationError('config', 'object or undefined', typeof config)
  }

  // ID 验证
  if (config.id !== undefined) {
    try {
      TypeValidator.validateId(config.id, 'config.id')
    } catch (error) {
      throw new ValidationError('config.id', 'valid id', error.message)
    }
  }
  // ...
}
```

**文件变更**:
- `lowcode/core/TypeValidator.js` - 新增
- `lowcode/core/BaseEntity.js` - 添加验证
- `lowcode/core/HookManager.js` - 添加验证

### 4.2 使用类型验证

```javascript
import { TypeValidator, ValidationError } from 'lowcode/core/TypeValidator.js'

// 基本类型验证
TypeValidator.validateString(name, 'name')
TypeValidator.validateNumber(age, 'age')
TypeValidator.validateFunction(callback, 'callback')

// 枚举验证
TypeValidator.validateEnum(status, EntityState, 'status')

// 对象验证
TypeValidator.validateObject(config, 'config')

// 数组验证
TypeValidator.validateArray(items, 'items')

// ID 验证
TypeValidator.validateId(id, 'id')
```

### 4.3 处理异常

```javascript
import { ValidationError } from 'lowcode/core/TypeValidator.js'

try {
  // 可能抛出异常的操作
  await pluginRegistry.destroy('non-existent-plugin')
} catch (error) {
  if (error instanceof ValidationError) {
    console.error('验证错误:', error.field, error.expected, error.actual)
  } else {
    console.error('其他错误:', error)
  }
}
```
