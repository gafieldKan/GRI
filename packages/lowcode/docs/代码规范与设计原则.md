# GRI 低代码平台代码规范与设计原则

## 一、总则

本规范基于 SAP 企业级应用设计理念，结合 GoF 设计模式，确保 GRI 全球资源整合平台具备高可扩展性、高可维护性和跨国业务支持能力。

## 二、面向对象设计原则

### 2.1 对象三大特性要求

#### 2.1.1 封装性 (Encapsulation)
- 所有业务实体必须使用类 (Class) 封装
- 内部状态必须私有化，通过公共方法访问
- 禁止直接暴露内部属性，使用 getter/setter
- 敏感数据必须进行访问控制

```javascript
// ✅ 正确示例
class Order {
  #internalState // 私有字段
  
  constructor(config) {
    this._id = config.id
    this._status = config.status || 'pending'
  }
  
  getStatus() {
    return this._status
  }
  
  setStatus(status, context) {
    // 权限校验
    if (!context.user.canChangeStatus) {
      throw new Error('无权限')
    }
    this.#beforeStatusChange(status)
    this._status = status
    this.#afterStatusChange(status)
  }
}

// ❌ 错误示例
const order = {
  id: 'xxx',
  status: 'pending' // 直接暴露
}
```

#### 2.1.2 继承性 (Inheritance)
- 建立清晰的实体继承层次
- 基类定义通用行为，子类扩展特性
- 使用原型继承或 ES6 class extends

```javascript
// 基础资源类
class Resource {
  constructor(config) {
    this.id = config.id
    this.name = config.name
    this.status = 'active'
  }
  
  activate() { this.status = 'active' }
  deactivate() { this.status = 'inactive' }
}

// 餐厅继承资源
class Restaurant extends Resource {
  constructor(config) {
    super(config)
    this.cuisine = config.cuisine
    this.deliveryRange = config.deliveryRange
  }
  
  // 扩展方法
  getDeliveryInfo() {
    return { range: this.deliveryRange }
  }
}

// 厨房继承资源
class Kitchen extends Resource {
  constructor(config) {
    super(config)
    this.capacity = config.capacity
  }
}
```

#### 2.1.3 多态性 (Polymorphism)
- 同一接口支持不同实现
- 支持策略模式、工厂模式
- 运行时动态绑定

```javascript
// 支付策略接口
class PaymentStrategy {
  pay(amount, context) {
    throw new Error('子类必须实现')
  }
}

// 微信支付
class WechatPay extends PaymentStrategy {
  pay(amount, context) {
    // 微信支付实现
  }
}

// 支付宝支付
class AlipayPay extends PaymentStrategy {
  pay(amount, context) {
    // 支付宝实现
  }
}

// 工厂方法
class PaymentFactory {
  static create(type) {
    const strategies = {
      'wechat': WechatPay,
      'alipay': AlipayPay
    }
    return new strategies[type]()
  }
}
```

## 三、GoF 设计模式应用

### 3.1 创建型模式

#### 工厂模式 (Factory Pattern)
```javascript
class ComponentFactory {
  static createComponent(type, config) {
    const components = {
      'input': InputComponent,
      'select': SelectComponent,
      'table': TableComponent
    }
    return new components[type](config)
  }
}
```

#### 单例模式 (Singleton Pattern)
```javascript
class ConfigManager {
  static #instance
  
  static getInstance() {
    if (!this.#instance) {
      this.#instance = new ConfigManager()
    }
    return this.#instance
  }
  
  constructor() {
    if (ConfigManager.#instance) {
      throw new Error('单例实例已存在')
    }
  }
}
```

#### 构建器模式 (Builder Pattern)
```javascript
class QueryBuilder {
  select(fields) { this._select = fields; return this }
  from(table) { this._from = table; return this }
  where(condition) { this._where = condition; return this }
  build() { return new Query(this._select, this._from, this._where) }
}
```

### 3.2 结构型模式

#### 代理模式 (Proxy Pattern)
```javascript
class DataAccessProxy {
  constructor(realSubject) {
    this.realSubject = realSubject
  }
  
  getData(id, user) {
    // 前置处理：权限校验
    this.#checkPermission(user)
    // 调用真实对象
    return this.realSubject.getData(id)
  }
  
  #checkPermission(user) {
    // 权限校验逻辑
  }
}
```

#### 适配器模式 (Adapter Pattern)
```javascript
// 适配不同地图服务商
class MapAdapter {
  constructor(provider) {
    this.provider = provider
  }
  
  showLocation(lat, lng) {
    // 统一接口
    return this.provider.display(lat, lng)
  }
}
```

#### 装饰器模式 (Decorator Pattern)
```javascript
class LoggerDecorator {
  constructor(service) {
    this.service = service
  }
  
  execute(data) {
    console.log('执行前:', new Date())
    const result = this.service.execute(data)
    console.log('执行后:', new Date())
    return result
  }
}
```

### 3.3 行为型模式

#### 策略模式 (Strategy Pattern)
```javascript
class PricingStrategy {
  constructor(strategy) {
    this.strategy = strategy
  }
  
  calculatePrice(basePrice, context) {
    return this.strategy.calculate(basePrice, context)
  }
}
```

#### 观察者模式 (Observer Pattern)
```javascript
class Observable {
  constructor() {
    this.observers = []
  }
  
  subscribe(observer) {
    this.observers.push(observer)
  }
  
  notify(data) {
    this.observers.forEach(obs => obs.update(data))
  }
}
```

#### 模板方法模式 (Template Method Pattern)
```javascript
class BaseWorkflow {
  execute(context) {
    this.beforeExecute(context)
    this.doExecute(context)
    this.afterExecute(context)
  }
  
  beforeExecute(context) {} // 钩子
  doExecute(context) {}     // 子类实现
  afterExecute(context) {}  // 钩子
}
```

## 四、钩子 (Hooks) 设计规范

### 4.1 生命周期钩子

所有核心对象必须预留以下钩子：

```javascript
class BaseEntity {
  // 创建前
  beforeCreate(context) { /* 扩展点 */ }
  
  // 创建后
  afterCreate(context) { /* 扩展点 */ }
  
  // 更新前
  beforeUpdate(context) { /* 扩展点 */ }
  
  // 更新后
  afterUpdate(context) { /* 扩展点 */ }
  
  // 删除前
  beforeDelete(context) { /* 扩展点 */ }
  
  // 删除后
  afterDelete(context) { /* 扩展点 */ }
}
```

### 4.2 业务钩子

```javascript
class OrderProcessor {
  constructor() {
    this.hooks = {
      onValidate: [],
      onBeforePay: [],
      onAfterPay: [],
      onBeforeShip: [],
      onAfterShip: [],
      onCancel: [],
      onRefund: []
    }
  }
  
  // 注册钩子
  addHook(name, callback) {
    if (this.hooks[name]) {
      this.hooks[name].push(callback)
    }
  }
  
  // 触发钩子
  async triggerHook(name, context) {
    for (const hook of this.hooks[name] || []) {
      await hook(context)
    }
  }
}
```

### 4.3 插件钩子

```javascript
class PluginSystem {
  constructor() {
    this.plugins = []
  }
  
  // 注册插件
  register(plugin) {
    this.plugins.push(plugin)
  }
  
  // 调用插件钩子
  async callHook(hookName, data) {
    for (const plugin of this.plugins) {
      if (plugin[hookName]) {
        await plugin[hookName](data)
      }
    }
  }
}
```

## 五、配置化设计规范

### 5.1 配置优先原则

所有可配置项必须通过配置中心管理：

```javascript
class ConfigurableEntity {
  constructor(config) {
    this.config = {
      // 基础配置
      id: config.id,
      name: config.name,
      
      // 功能开关
      features: {
        enableApproval: config.enableApproval || false,
        enableNotification: config.enableNotification || true,
        enableAudit: config.enableAudit || true
      },
      
      // 区域配置
      region: {
        timezone: config.timezone || 'UTC',
        locale: config.locale || 'zh-CN',
        currency: config.currency || 'CNY'
      },
      
      // 业务规则
      rules: {
        maxOrderAmount: config.maxOrderAmount || 10000,
        minOrderAmount: config.minOrderAmount || 0,
        allowedPaymentMethods: config.allowedPaymentMethods || []
      }
    }
  }
}
```

### 5.2 配置分层

```javascript
const configLayers = {
  // 1. 系统默认配置
  system: require('./config/default'),
  
  // 2. 租户配置
  tenant: require('./config/tenant'),
  
  // 3. 组织配置
  organization: require('./config/org'),
  
  // 4. 用户配置

// 配置合并策略
function getConfig(key) {
  return merge(
    configLayers.system[key],
    configLayers.tenant[key],
    configLayers.organization[key],
    configLayers.user[key]
  )

```

### 5.3 功能开关 (Feature Flags)

```javascript
class FeatureFlags {
  constructor() {
    this.flags = new Map()
  }
  
  register(name, defaultValue) {
    this.flags.set(name, defaultValue)
  }
  
  isEnabled(name, context = {}) {
    const flag = this.flags.get(name)
    if (!flag) return false
    
    // 支持条件判断
    if (flag.conditions) {
      return flag.conditions.every(cond => 
        this.evaluateCondition(cond, context)
      )
    }
    
    return flag.enabled
  }
}

// 使用示例
const features = new FeatureFlags()
features.register('multiCurrency', {
  enabled: true,
  conditions: [
    { field: 'region', operator: 'in', value: ['CN', 'US', 'EU'] }
  ]
})
```

## 六、全球化/跨国业务支持

### 6.1 多语言支持 (i18n)

```javascript
class I18nService {
  constructor() {
    this.translations = new Map()
    this.currentLocale = 'zh-CN'
  }
  
  t(key, params = {}) {
    const translation = this.translations.get(key)
    if (!translation) return key
    
    // 参数替换
    let result = translation[this.currentLocale] || key
    Object.entries(params).forEach(([k, v]) => {
      result = result.replace(`{${k}}`, v)
    })
    return result
  }
  
  // 区域格式化
  formatNumber(value, locale) {
    return new Intl.NumberFormat(locale).format(value)
  }
  
  formatCurrency(amount, currency, locale) {
    return new Intl.NumberFormat(locale, {
      style: 'currency',
      currency
    }).format(amount)
  }
  
  formatDate(date, locale) {
    return new Intl.DateTimeFormat(locale).format(new Date(date))
  }
}
```

### 6.2 多时区支持

```javascript
class TimeZoneService {
  constructor() {
    this.userTimezones = new Map()
  }
  
  // 设置用户时区
  setUserTimezone(userId, timezone) {
    this.userTimezones.set(userId, timezone)
  }
  
  // UTC 转用户本地时间
  toLocalTime(utcDate, userId) {
    const timezone = this.userTimezones.get(userId) || 'UTC'
    return dayjs(utcDate).tz(timezone).format()
  }
  
  // 用户时间转 UTC
  toUTC(localDate, userId) {
    const timezone = this.userTimezones.get(userId) || 'UTC'
    return dayjs(localDate).tz(timezone).utc().format()
  }
}
```

### 6.3 多货币支持

```javascript
class CurrencyService {
  constructor() {
    this.exchangeRates = new Map()
  }
  
  // 货币转换
  convert(amount, from, to) {
    if (from === to) return amount
    
    const rate = this.getExchangeRate(from, to)
    return amount * rate
  }
  
  // 获取汇率
  getExchangeRate(from, to) {
    const key = `${from}_${to}`
    return this.exchangeRates.get(key) || 1
  }
  
  // 更新汇率
  updateRate(from, to, rate) {
    this.exchangeRates.set(`${from}_${to}`, rate)
  }
}
```

### 6.4 数据驻留合规

```javascript
class DataResidencyService {
  constructor() {
    // 数据驻留规则
    this.residencyRules = {
      'EU': ['DE', 'FR', 'IT', 'ES'],  // 欧盟数据
      'CN': ['CN'],                     // 中国数据
      'US': ['US']                      // 美国数据
    }
  }
  
  // 获取数据存储位置
  getDataLocation(country) {
    for (const [region, countries] of Object.entries(this.residencyRules)) {
      if (countries.includes(country)) {
        return region
      }
    }
    return 'default'
  }
  
  // 校验数据跨境
  canTransferData(from, to, dataType) {
    // GDPR 等合规检查
    if (dataType === 'personal' && from === 'EU' && to !== 'EU') {
      return this.hasAdequacyDecision(to)
    }
    return true
  }
}
```
