## 二、详细优化内容

### 1. 表达式引擎安全性增强

**优化文件**: `lowcode/engine/ExpressionEngine.js`

**新增安全机制**:
- 安全沙箱（SecuritySandbox）：防止原型链攻击
- 危险函数拦截：阻止 eval、require 等危险函数调用
- 表达式验证：执行前进行安全检查
- 执行超时保护：防止死循环

**安全配置**:
```javascript
const SECURITY_CONFIG = {
  blockedKeywords: ['constructor', '__proto__', 'prototype'],
  blockedFunctions: ['eval', 'Function', 'require', 'import'],
  maxRecursionDepth: 10,
  maxExecutionTime: 1000,
}
```

**内置安全函数库** (40+ 函数):
- 数学函数：abs, round, floor, ceil, min, max, pow, sqrt, random
- 字符串函数：length, trim, substr, slice, split, join, replace
- 逻辑函数：if, and, or, not, eq, ne, gt, lt, gte, lte
- 类型判断：isString, isNumber, isBoolean, isArray, isObject
- 类型转换：toString, toNumber, toBoolean, toArray
- 数组函数：sum, count, first, last, filter, map, sort, find

## 五、使用指南

### 表达式引擎使用

```javascript
import { expressionEngine } from 'lowcode'

// 安全表达式计算
const result = expressionEngine.evaluate('{{ order.price * order.quantity }}', {
  order: { price: 100, quantity: 3 }
})

// 注册自定义安全函数
expressionEngine.registerFunction('formatCurrency', (value) => {
  return `¥${Number(value).toFixed(2)}`
})

// 安全性：危险操作会被拦截
try {
  expressionEngine.evaluate('{{ eval("malicious") }}')
} catch (error) {
  console.log('安全拦截:', error.message)
}
```

### 数据源组件使用

```jsx
import { DataSourceForm, DataSourceList } from 'lowcode/components/DataSourceConfig'
import 'lowcode/components/DataSourceConfig/styles.css'

function DataSourceManager() {
  const [editing, setEditing] = useState(null)

  return (
    <div>
      <DataSourceList
        onEdit={(ds) => setEditing(ds)}
        onDelete={(ds) => console.log('已删除:', ds.name)}
      />
      {editing && (
        <DataSourceForm
          dataSourceId={editing.id}
          onSave={(config) => {
            console.log('已保存:', config)
            setEditing(null)
          }}
          onCancel={() => setEditing(null)}
        />
      )}
    </div>
  )
}
```

### 国际化使用

```javascript
import { i18nManager, t } from 'lowcode'

// 切换语言
i18nManager.setLocale('en-US')

// 翻译文本
const saveText = t('common.save') // "Save"
const componentText = t('lowcode.component') // "Component"

// 带参数翻译
i18nManager.t('validation.maxLength', { max: 50 })
// "Length must be no more than 50 characters"
```
