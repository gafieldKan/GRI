## 二、本次新增功能

### 2.1 单点登录 (SSO) 集成 ✅

**实现文件**:
- `engine/SSOManager.js` - SSO 管理器核心
- `components/SSO/LoginPanel.jsx` - 登录面板 UI

**支持协议**:
| 协议 | 说明 |
|------|------|
| OAuth2 | 标准 OAuth2 授权流程 |
| OAuth2 PKCE | 增强的 PKCE 模式 |
| OpenID Connect | OIDC 身份认证 |
| SAML | 企业级 SAML 2.0 |
| LDAP | 企业目录服务 |
| CAS | 统一认证服务 |

**功能特性**:
- 自动授权码交换 Token
- Token 自动刷新
- 状态验证 (防 CSRF)
- PKCE 代码挑战
- 用户信息同步
- 登出回调

**使用示例**:
```javascript
import { ssoManager, AuthProtocol } from 'lowcode'

// 初始化配置
ssoManager.init({
  protocol: AuthProtocol.OAUTH2,
  authorizeUrl: 'https://auth.example.com/oauth/authorize',
  tokenUrl: 'https://auth.example.com/oauth/token',
  userInfoUrl: 'https://auth.example.com/oauth/userinfo',
  clientId: 'your-client-id',
  clientSecret: 'your-client-secret',
  redirectUri: 'https://your-app.com/callback',
  scope: 'openid profile email',
})

// 开始登录
await ssoManager.login()

// 处理回调
await ssoManager.handleCallback(window.location.href)

// 获取用户信息
const user = ssoManager.getUser()
const token = ssoManager.getToken()

// 刷新 Token
await ssoManager.refreshToken()

// 登出
ssoManager.logout()
```

### 2.2 多人协同编辑基础框架 ✅

**实现文件**:
- `engine/CollaborationManager.js` - 协同管理器核心
- `components/Collaboration/CollaborationPanel.jsx` - 协同面板 UI

**核心功能**:
| 功能 | 说明 |
|------|------|
| 实时连接 | WebSocket 双向通信 |
| 操作锁机制 | 资源级锁定防止冲突 |
| 冲突检测 | 版本冲突检测与解决 |
| 游标同步 | 实时游标位置共享 |
| 心跳保活 | 自动心跳检测离线 |
| 自动重连 | 断线自动重连 |

**冲突解决策略**:
- LAST_WRITE_WINS - 最后写入获胜
- FIRST_WRITE_WINS - 先写入获胜
- MERGE - 自动合并
- MANUAL - 手动解决

**使用示例**:
```javascript
import { collaborationManager, OperationType } from 'lowcode'

// 初始化
collaborationManager.init({
  wsUrl: 'ws://localhost:8080',
  roomId: 'doc-123',
  userId: 'user-1',
  userName: '张三',
  conflictStrategy: 'last_write_wins',
})

// 连接服务器
await collaborationManager.connect()

// 获取资源锁
const { success, lock } = await collaborationManager.acquireLock('field-1')

// 执行协同操作
await collaborationManager.insert('users.0.name', '李四')
await collaborationManager.update('users.0.age', 25)
await collaborationManager.delete('users.0', previousValue)

// 更新游标
collaborationManager.updateCursor({ line: 10, column: 5 })

// 监听远程操作
collaborationManager.on('remote:operation', (op) => {
  console.log('远程操作:', op)
})

// 断开连接
collaborationManager.disconnect()
```
