## 五、GRI 应用开发建议

### 5.1 推荐架构

```
GRI 应用
├── domain/           # 领域模型 (基于 BaseDomain 扩展)
│   ├── restaurant/   # 餐厅领域
│   ├── dish/         # 菜品领域
│   ├── order/        # 订单领域
│   ├── cart/         # 购物车领域
│   └── user/         # 用户领域
├── repository/       # 数据访问层
├── service/          # 业务服务层
├── state/            # 状态管理 (Zustand)
└── components/       # UI 组件
```

### 5.2 开发顺序

1. **第一步**: 在 GRI 目录创建应用框架
2. **第二步**: 实现商品、订单、购物车领域模型
3. **第三步**: 实现商家列表、菜单、购物车 UI
4. **第四步**: 对接支付和配送服务
5. **第五步**: 完善订单管理和评价功能
