联合国资源分类与使用说明

CPC 对产品（货物与服务）进行分类。可以从联合国进入 CPC Ver.3.0，再按门类、大类、中类、小类、子类逐层查看；左侧分类树、中部层级图和右侧说明同步更新。

版本与来源

采用联合国统计司 UN CPC Ver.3.0 的编码结构与产品目录。本页数据全部经 GRI 本体 API（/api/taxonomy/resource）实时读取，不内嵌副本；编码按文本保存，保留 01、011 等前导零。

中文名称

中文名称为工作译名：由术语向的机器翻译产生，非联合国官方中文。官方英文原名与范围说明保留在上游真源（scripts/reference-data），本视图经 API 仅取中文名称字段。

视图与导出

中部可切换层级图（当前层级的直接子级方块，点击进入）与列表（表格，点击一行进入）。可导出当前分支或完整目录为 CSV / JSON，层级图可导出 PNG；收藏和笔记保存在当前浏览器。

分类层级由父级推导，不单独存储于请求；「联合国」与「CPC Ver.3.0」两级为视图层合成，上游数据模型以门类为根。

快捷操作

Ctrl K 搜索；Esc 返回上级；+ − 缩放。桌面层级图支持滚轮缩放、拖动平移。手机上直接点击方块或使用分类树。
