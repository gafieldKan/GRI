## ✅ 验收标准

1. 可切 **学科体系 / K12**（默认学科体系）；维度 A 显示 **N 座峰**（MATH 9）；维度 B 显示 学段→年级→册/章；切换**不丢学科与当前峰**。
2. 形象达人本世界档（等距拟真、多峰群山、路径/站点立体），与学习世界/人本世界**同一世界语言**（共享件复用，无第二套画法）。
3. **直观**：关键信息首屏可见；隐喻可读（山/营地/雾/旗/天路）。
4. **易操作**：核心路径 ≤2 步；空态/异常有兜底。
5. 既有功能不回归；`build:h5` 通过；真实浏览器（playwright）：切两维度 + 换学科 + 点峰/进营地 + 三动作，**pageerror=0**。
6. 零裸色（新增/改动文件三重 grep 空）；共享画法仍零色值。
7. `verify.sh` 末行 `FAIL=0`；不 commit/不 checkout；凭据零泄漏。
