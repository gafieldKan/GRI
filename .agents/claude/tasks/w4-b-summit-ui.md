## ✅ 验收标准

1. 可切 **学科知识体系 / K12 阶段**（默认前者）；维度 A 显示 **N 座峰**（MATH 10）；维度 B 显示 学段→年级→册/章 + 分支归属；切换**不丢学科与当前峰**。
2. **延续性**：每峰可见 K12 年级区间与学科纵深段（可读、可懂、不误导）。
3. 形象达人本世界档，与学习世界/人本世界**同一世界语言**（共享件复用、无第二套画法）。
4. 直观：关键信息首屏可见，隐喻可读；易操作：核心路径 ≤2 步，空态有兜底。
5. 既有功能不回归；`build:h5` 通过；真实浏览器：切两维度 + 换学科 + 选峰/进营地 + 三动作，**pageerror=0**。
6. 零裸色（三重 grep 空）；共享画法零色值；分支权威依据可展示且不编造。
7. `verify.sh` 末行 `FAIL=0`；不 commit/不 checkout；凭据零泄漏。
